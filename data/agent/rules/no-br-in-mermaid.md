Mermaid 节点标签中禁止使用任何换行：`<br/>`、`<br>`、反斜杠 n **全部都会**在 mermaid UMD/SVG 序列化环境触发 void element 解析不匹配报错 / 页面白屏。

正确写法：**单行标签**，多段信息用 `·`、`｜`、`-`、`;` 等行内符号分隔，绝不换行：
```text
L1["医共体党委书记·院长 ｜ 双组长"]
JG["技术指导组 ｜ 总院临床专科团队 ｜ 制定规范·标准·指标 ｜ 指导培训·统一执行"]
```
而不是：
```
A["第一步<br/>详细说明"]
```
