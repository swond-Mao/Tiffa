## 纠正指导

检测到连续 8 次或以上的工具调用而没有文字说明。

### 规则

- **同参数同工具**：同一工具连续调用 3 次时必须停止并换方法
- **ask 循环**：连续调用 ask 超过合理次数前，先自己分析判断
- **工具链**：每个工具调用后必须有中文文字说明，不能纯工具流

### 正确做法

1. **先读后写**：修改文件前先 read 确认内容
2. **合并调用**：能用一次工具完成的不要拆成多次
3. **自行判断**：遇到不确定的，先查阅代码/文档，不要直接问用户
4. **一次问完**：需要 ask 用户时，收集所有问题一次性询问

请停止当前循环，重新规划执行方式。
