# PPT 制作方法论（统一入口）

> **第一铁律：内容是汇报材料，绝不妥协。** 模板只是视觉增强，没有合适模板就手搓，禁止为套模板改内容。
> **第二铁律：禁止脱离设计指导手搓。** 无论走哪条管线，大纲/每页结论/视觉语言必须先按本技能方法论产出并确认。

## 两条管线（读本技能到实现层才路由）

| 管线 | 委托技能 | 适用 | 技术栈 |
| --- | --- | --- | --- |
| **A 从零设计** | `skill://pptx-designer` | 无模板 / 模仿模板风格 / 只有材料 | JS/pptxgenjs → 原生 .pptx |
| **B 模板驱动** | `skill://pptx-template-reverse` | 有模板：逆向→主题→按版式填 deck | python-pptx → 原生 .pptx |

> 管线 B 轻量分支：模板版式已够用、只填内容 → `skill://pptx-from-layouts`（不新建版式）。
> **内容风格改造**（区别于管线 B 母版设计）：用户已有**内容 deck**，要把某几页**视觉高级化**（保留原风格）→ 走 `skill://pptx-designer` 的 `references/deck-restyle.md`（提取原 deck 色板/字体/版式/图片 → build.js 重做内容页视觉）。
> **关键区分**：管线 B = **基于母版设计**（逆向母版/版式结构做可复用主题）；deck-restyle = **利用现有内容做风格改造**（内容已有，只改内容页视觉）。
> 快速 HTML 演示（非正式汇报）→ `skill://dashiai-ppt`（即将废弃，仅用户明确要求时）。

## 路由决策表（Step 0 意图澄清后判定）

| 用户意图 | 路由 | 说明 |
| --- | --- | --- |
| 做 PPT，无模板 | **A** | 从零设计，走完整方法论 |
| 按 XX 模板做 PPT | **B** | 逆向模板→主题→按版式填 deck |
| 只逆向 XX 模板 | **B（Step1-5）** | 纯主题构建，不做 deck |
| 模仿 XX 模板风格 | **A** | profile_template 提色板/字体作基线，JS 设计 |
| 模板版式已够，只填内容 | **B 轻量分支** | pptx-from-layouts 直接填充 |
| 有内容 deck，某几页要高级化 | **A + deck-restyle** | 保留原风格，build.js 重做内容页视觉 |
| 套原风格改造某页 | **A + deck-restyle** | 提取原色板/字体/版式/图片 → 高级版式 |

## 标准流程（三确认制：大纲→设计语言→导出）

```
Step 0  意图澄清（ask：有无模板/模板怎么用/文字稿有没有/图片来源）→ 路由决策
Step 1  文字稿：无稿先出文字稿（材料提取或生成），不允许无稿进大纲
Step 2  大纲：OUTLINE.md，每页必填——页面定位/内容类型/布局类型/本页结论(一句话)/拆页标记
        → 【确认①】页数可增删，用户确认前不进下一步
Step 3  设计语言：色板(≤4 hex)/字体(≤2)/版式方向 → 【确认②】
Step 4  按路由委托管线：read 管线 SKILL.md 执行（管线被委托时跳过需求澄清）
Step 5  QA：管线自带渲染/校验 + check_parts（无重复 part）
Step 6  交付：.pptx + 讲稿备注 → 【确认③】导出前用户确认
```

## 方法论核心（细节见 references/）

- 决策顺序不可倒置：文字稿 → 内容 → 布局 → 主题 → 设计稿 → 模板。禁止先挑版式再硬塞内容。
- 每页一个结论：本页要说清一句话，说不清这页不过。
- 视觉统一：全篇一套色板 ≤4 hex + ≤2 字体；风格只约束视觉语言，不约束布局（布局永远由内容决定）。
- 每页 ≥1 视觉锚点（巨型数字 ≥48px / 大图 ≥40% B 区 / 大色块）；相邻页版式不重复。
- 硬约束自检：内容完整性（模板不得导致内容删减扭曲）、文本不溢出、配色∈色板、母版齐全。
- 详细方法论 `references/methodology.md`；设计宪法 `references/design-core.md`。

## 备注与讲稿

- 演讲者备注默认按汇报材料对应段落写入（照读稿），页数/时长按汇报场合调整（约 200-240 字/分钟）。
- 章节页备注为板块转场短句。
