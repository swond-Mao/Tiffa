# PPT 制作方法论核心

> 内容决定版式，风格统一色调，每页一个明确设计依据。本文件是大技能 `skill://ppt` 的方法论核心，提炼自 pptx-designer 长期实践；细节（布局模式库/组件 API）在管线技能 references 内。

## 一、六步流程（内容优先，用户确认制）

| 步骤 | 产物 | 决策 | 确认点 |
| --- | --- | --- | --- |
| 0 文字稿 | 文字稿（外部技能/用户提供/材料提取） | 只有主题先出文字稿，不允许无稿进大纲 | — |
| 1 大纲 | OUTLINE.md（每页含布局类型） | 叙事→页骨架→每页结论；装不下标拆页 | **确认①** |
| 2 主题/设计语言 | design.json 或主题模板（色板/字体） | 用户指定 / 模板逆向 / 场景推荐 | **确认②** |
| 3 细化设计稿 | DESIGN.md（每页文字/分布/卡片/图片/强调） | 内容→布局→文字→卡片→图位→强调 | — |
| 4 实现 | 按路由：A 管线 pages/*.js 或 B 管线 build_deck 脚本 | 对照 DESIGN.md | — |
| 5 导出/交付 | .pptx + 讲稿备注 + QA 渲染 | 用户确认后编译 | **确认③** |

决策顺序（不可倒置）：文字稿 → 内容 → 布局 → 主题 → 设计稿 → 模板。

## 二、大纲每页必填（OUTLINE.md 契约）

| 字段 | 说明 |
| --- | --- |
| 页面定位 | 封面/目录/章节/内容/结束 |
| 内容类型 | 数据/KPI、对比、流程、图片、观点、列表… |
| 布局类型 | L-* 模式（A 管线 layout-library.md；B 管线按模板版式能力定） |
| 本页结论 | 一句话——这页要传达什么 |
| 拆页标记 | 装不下标 5a/5b |

大纲由用户确认（页数可增删）后才进入下一步。

## 三、设计稿每页必填（DESIGN.md 契约）

1. **本页结论**：一句话，说不清这页不过
2. **文字内容与分布**：标题/正文/数字，哪些字放哪块区域
3. **卡片格式**：几块卡片/色块/列表/表格，内容怎么装
4. **图片张数与图位**：0-4 张，先定图位再组织文字
5. **强调用法**：全局色调下强调色用在哪（某数字/系列/色块，≤10% 面积）
6. **拆页落实**：拆页展开为两页

> 色调是全局的——Step 2 定，设计稿每页不重复选色调，只标强调用法。

## 四、内容类型 → 布局决策矩阵

| 内容类型 | 布局类型 | 强调用法建议 |
| --- | --- | --- |
| 开场/封面 | cover | 主色大面积 + 强调色点缀 |
| 导航/目录 | toc | 主色 40% + 强调色编号 |
| 章节切换 | section | 主色 60% + 强调 15% |
| 核心数据/KPI | metrics/duel | 强调色 15-20%（荧光/高饱和） |
| 趋势/时间序列 | trend | 图表双色（主 + 对比） |
| 排行/分布 | ranking | 表头主色 + 高亮强调 |
| 对比/问题对策 | compare | 双栏各一强调色 |
| 流程/步骤 | process | 编号强调色循环 |
| 架构/关系 | network | 主色阶 + 少量强调 |
| 观点/结论 | conclusion/quote/statement | 主色 + 金句强调 |
| 图片/场景 | photo-left/right/top | 图承载色调，文字用中性 |
| 团队/案例集 | grid | 统一图框 + 主色标签 |
| 项目拆解 | case | 图 + 编号强调 |

## 四·五 模板检索（taxonomy）

正文页模板选择按 `skill://pptx-designer/references/taxonomy.md` 四层检索（L1 定位 → L2 内容类型 → L3 布局族 → L4 候选），强制相邻页 L3 防撞。容量基准：纯文字 600-800 字 / 多卡片每卡 80-120 字 / 左图右文 200-300 字 / 图表 80-120 字+洞察 / 金句 20-50 字。

## 五、模板匹配红线

- 模板与内容冲突 → 换模板或手搓，**绝不改内容**
- 模板装不下内容 → 拆两页，不压缩内容
- 模板字段与内容类型不匹配 → 手搓，不硬套
- 文字量 × 图量自检：少文字页禁堆正文；多文字页禁大图撑版面；图表页必须有洞察；图片页必须有图说

## 六、硬约束（每页自检）

1. 大纲/设计稿契约齐全，决策顺序正确
2. 每页 ≥1 视觉锚点（巨型数字 ≥48px / 图 ≥40% B 区 / 大色块）
3. 相邻页布局模式不重复；对称版式全篇 ≤2 页
4. 图片位先定，文字围绕图组织
5. 配色 ∈ 色板；字号符合阶梯；文本不溢出
6. 内容页必有母版（标题块 + 页码）；hero 页有冲击力版式
7. **内容完整性**：模板/布局不得导致内容删减或扭曲——违反即返工

## 七、模板驱动管线（B）特别约定

- 逆向主题时，版芯/标题位置按 probe 出的模板装饰位置定，避开页头装饰与底部装饰带
- 用模板版式填 deck：几何遵循模板版式占位符，文案/结论遵循本方法论（每页结论 + 讲稿）
- 讲稿按汇报材料对应段落写入，章节页为转场短句
