# 视频生成提示词（Video Prompt Crafting）

基于 MiniMax H3 官方使用手册蒸馏。核心原则：**H3 擅长理解明确的画面指令，不擅长抽象比喻**——多写看得见的画面，少写需要"意会"的句子。

## 完整公式（必须三段式）

```
完整提示词 = 参考素材说明 + 核心创意 + 画面过程说明
```

三段缺一不可。只写一段话不分段 = 最典型的低级错误。

## 要素一：参考素材说明

告诉模型你上传的**每个素材是干什么用的**：

- **写清素材编号**：按上传顺序 `@图片1`、`@音频2`、`@视频3`
- **写清每个素材的用途**（按需选用）：
  - 人物参考（锁定脸/形象）
  - 物体参考（锁定物体）
  - 场景参考（锁定场景）
  - 关键帧（锁定帧，有首帧/尾帧需求时明确提出）
  - 音色参考（锁定音色）
  - 故事版（按故事版分镜生成镜头内容）
  - 风格参考（按图片风格生成类似内容）
  - 构图参考（按图片物体构图生成对应构图）
  - 音频复用（生成视频的音频直接复用参考音频）
  - 音频部分复用（某个声音轨道/某个时间段部分复用）
  - 动作参考（锁定动作）
  - 运镜参考（锁定运镜）
  - 视频编辑（对视频某内容增删改）
- **没有上传素材时整段跳过**
- 素材中非常想保持的特征，明确写出来（一致性更好）
- 音频复刻/部分复刻时，对人声/歌词保持要求高 → 强烈建议补充具体歌词文本
  - 例：`@音频1 作为目标视频的音频复刻素材，具体歌词是："ABCDEFGHIJKLMN"。`

## 要素二：核心创意

用**一句话锁定全片信息**，必须包含：

- **主体**：谁/什么（人/物/动物/其他）
- **地点**：在哪里
- **事件**：在做什么
- **题材/风格**：什么调性（写实/动画/电影感/广告片/纪录片……）
- **特殊风格列举**：赛博朋克/霓虹灯美学/涂鸦风 等
- **特殊运镜**：要不要特殊镜头（航拍/一镜到底/慢动作……）
- **默认会切镜**（如不想要切镜需明确说明）

### 运镜风格
- 写清即可；**环绕运镜建议用 `truck left + pan right` 或 `truck right + pan left` 描述，而非直接说"环绕运镜"**

### 切镜风格
- 普通切镜（cut）
- 叠化切镜（fade）
- 随着节奏卡点切镜
- 快切

示例：`一位穿汉服的年轻女子（@图片1）在樱花纷飞的庭院里舞剑，古典国风，电影质感，一镜到底。`

## 要素三：画面过程说明

按时间轴或故事线分段写，每个分镜/时间段包含两部分：

### 想要（画面里要出现什么）
- 画面景别 + 内容 + 运镜 + 动作 + 台词 + 音效
- **以切镜 shot 作为时间戳分段**，每个 shot 内部写好景别、具体内容、shot 内运镜、人物台词、音效
- **台词长短尽量和镜头长短对齐**（很多口型问题来自这里）
- 一句台词跨 shot：用"接着上个 shot 继续说"表明是跨 shot 对白
- 元素和引用素材有关联 → 用 `@图片1`、`@音频1` 强调
- **想要画面中出现具体文字/Logo/标题/标语/按钮文案 → 一定要把文字原文写出来**
  - 例：`画面中出现英文："H3"`
  - 例：`手机屏幕上显示标题："AI Video Creation"，按钮文字为："Start Now"`

### 不想要（视频里不要出现什么）
- 不想要 BGM 时明确写明，建议在提示词最后写：
  - `非叙事性音乐：N/A`
  - 或英文：`"non_diegetic_music": N/A`
  - 再补一句"不要额外添加背景音乐"
- **尽量少写比喻句，多写看得见的画面**
- 如有台词，必须明确具体内容
  - 例：`一位穿汉服的年轻女子说："你来了，剑等你好久了。"`

示例：
```
0-3 秒：全景，女子（@图片1）从画面左侧缓步走入樱花庭院（@图片2），背景虚化，没有对白，只有脚步声。
3-8 秒：切镜到女子（@图片1）的中景，她拔出长剑（@图片3），缓缓起势，樱花瓣从树上飘落。镜头推进。
8-12 秒：切镜到特写，剑光一闪，慢动作，樱花被剑气激得四散。
非叙事性音乐：N/A
```

## 镜头怎么拆（Shot 拆解规则）

H3 有基础分镜能力，对切镜点遵从较强。想生成更好：

- **台词长短**与画面变化内容须合乎每个 shot 的长短逻辑——不要 3s shot 说很大一段话
- **跨 shot 台词**：H3 能响应 J-cut / L-cut，只要明确写出一句台词跨了哪些 shot
- **画内/画外说话人**：画面内说话人写清是哪个角色说的；画面外说话人写清是画外说话人；发生画内外转化（因切镜）时明确写出来
  - 例：`一个画外音响起说：Wake up Wake up。之后切镜到一个中年妇女的近景，她是画外音的主人，她继续说道：It's time to go to school !`
- **切镜一致性保持**：切镜时明确写出切到什么景别、具体主体是之前哪个角色，有助于跨镜头一致性

## 三类模式，提示词分别怎么写

### 1. 上传多模态素材融合（多模态参考）
同时上传：人物图 + 动作视频 + 场景图 + 音乐。每个素材都要写清角色：
- `@图片1 → 人物参考（锁脸）`
- `@视频1 → 动作参考（锁动作）`
- `@音频1 → 节奏/情绪参考`

示例：`@图片1 是人物参考（锁这位女子的脸），@视频1 是动作参考（用里面的舞剑动作），@音频1 是情绪参考（古风配乐）。让这位女子在樱花庭院里按视频里的动作舞剑。`

### 2. 上传图片生成视频（图生视频）
- 只上传 1 张图：说清楚是**首帧**（视频开头画面）还是**尾帧**（视频结尾画面）
- 上传 2 张图（首+尾帧）：H3 **不会自动加切镜**，只补两帧之间的动作、光影、声音

示例：`@图片1 是首帧参考图：女子持剑站在樱花树下。让她从持剑起势到舞剑完毕，自然衔接，不要切镜。`

### 3. 纯文字生成视频
不依赖参考素材，直接根据文字建立主体、场景、动作。这种模式：
- **文字描述要更具体**（主体外观、场景细节、动作描述都要写清）
- 多用「**大全景交代空间 + 中景承载动作 + 特写强调细节**」的分层写法

示例：`写实自然纪录片风格，电影级真实光影。清晨的薄雾中，在广阔的湿地芦苇荡里，一只优雅的白鹤单腿站立在浅水中，缓慢转头看向镜头……`

## 容易踩的坑（自查表）

| 常见问题 | 怎么改 |
|----------|--------|
| 只写一段话没分段 | 按 3 段公式拆开写 |
| 素材上传了但没说用途 | 补一句「@图片1 是 XX 参考」 |
| 想用音乐但说「不要 BGM」 | 矛盾，要么删一个，要么分场景写 |
| 想一镜到底但写了很多分镜 | 全文保持一段情节描述，删掉【镜头 N】结构 |
| 想要主角脸一致但没传图 | 一定要上传人物参考图，并标注「人物参考」 |
| 提示词太短（无素材可参考时） | 至少写出主体外观 + 场景细节 + 动作 + 风格 |

## 完整示例（可直接改写复用）

### 大字幕 MV（trap 风格）
```
【参考素材说明】@图片3：场景视觉风格（街道/夜间/地下空间、压迫感构图、环境层次、影像颗粒）@图片2：文字包装样式（字体质感、图形设计、动态图形排版冲击力）@图片1：人物形象（脸、发型、服装轮廓、比例、气质、整体氛围）只参考指定维度，不直接复制参考图，不出现真实品牌、原参考图 logo/标题/可识别文字。
【核心创意】10秒，16:9 横版 trap MV。两位 fly detective 兄弟搭档在多个近景地下空间轮流对镜头 rap，全程跟随 trap 鼓点律动、卡点硬切，高反差印刷海报质感的英文块字随 bass hit 压屏出现。地下音乐录像带 + 时尚杂志拼贴 + 高时装质感，兄弟搭档式冷峻 performance。
【画面过程描述】Shot 1 — 面部极近特写 / 通道压迫感- 场景：狭窄通道或地下入口近景，参考 @图片3- 景别：面部极近特写（脸/眼神/肩颈/衣领局部）- 人物：Detective A 直视镜头开始 rap，眼神冷静锐利- 文字："TWO FLY" 巨大粗体英文压入画面上下，不遮挡眼睛- 律动：808 bass 砸下，"TWO FLY" 瞬间纵向压缩后回弹；hi-hat roll 时字母边缘高速细碎震动；"fly" 重音处扫描错位- 硬切 Shot 2 — 中近景半身 / 墙面文字背景- 场景：另一处墙面/海报墙近景（和 Shot 1 空间明显不同）- 景别：明显拉到中近景半身- 人物：Detective B 对镜头 rap，肩膀和头部跟 hi-hat 点拍，身体轻微前倾- 文字："CLUES" …（后续 shot 依次写明）
```

### 手绘特效（实拍 + 手绘发光动画融合）
```
【参考素材说明】无参考素材（纯文字生成视频）。
【核心创意】15 秒，16:9 横版视频。将实拍的傍晚老式电车车厢与手绘发光动画融合：空荡末班电车车厢里，乘客用手机单手临时拍摄，遇到手绘杏橙色发光线在车厢里连续变形（车票→纸燕子→毛毛虫→箭头→小帆船→迷你电车→蜗牛→雨伞→小鱼→整车晚霞云海），最后回到车票碎成纸屑。整体生活感、怀旧、温柔而略带哀愁。
【画面过程描述】0〜3 秒- 正向：实拍镜头从拍摄者指尖在起雾车窗上随手画弧线开始。指尖离开，雾痕变成杏橙手绘发光线（蜡笔粉笔混合质感），先贴指尖→绕食指→落掌心卷…（后续逐秒描述变形过程）
```

## 模型能力边界（MiniMax H3，写入提示词时注意）

- 输出时长：4-15 秒
- 分辨率：768p / 1440p（短边），24 FPS
- 宽高比：首/尾帧遵循原图；文生/全能参考 21:9 ~ 9:16
- 全部结果带声音，原生双声道
- 首/尾帧入口：0-2 张图，宽 [256,5760]，5:2~2:5
- 全能参考入口：图 ≤9 + 视频 ≤3 段（各 2-15s，总 ≤15s）+ 音频 ≤3（须配图/视频）+ 混合总 ≤12 文件
- 提示词上限：**不超过 7000 字符**
