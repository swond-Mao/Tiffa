# AI 生图实战指南（image-gen-playbook.md）

> 沉淀实测验证的生图策略，解决"生成什么/怎么生成/怎么用"。
> 与 SKILL.md 的管线路由互补——路由管"用哪条管线"，本文件管"怎么生成 + 怎么用"。

## 一、管线选择决策

| 场景 | 管线 | 理由 |
| --- | --- | --- |
| 常规生图（产品/意境/空间/背景/人像） | `gen` | Qwen Image 2.1 主力，提示词遵循好，中英文皆可 |
| 图片编辑/P图 | `edit` | Qwen Image 2.1 指令式编辑，支持多参考图 `--ref` |
| NSFW/特殊内容生图 | `krea2` | NSFW 等特殊需求走 krea2 |
| NSFW/特殊内容（编辑向） | `klein` | NSFW 等特殊需求走 klein（注意提示词遵循差，见下） |
| 艺术风/动漫 | `krea2` | 艺术质感 |

已退役：`ernie`（文字排版）、`zimage`（人像/通用）——Qwen Image 2.1 全面取代，文字渲染与常规场景都不再需要单独管线。

**klein 已知问题**（实测）：
1. **提示词遵循差**：给"xx 背景图"它会生成一张 **PPT 版式的图**（把用途当内容），而不是背景素材
2. **吃英文**：提示词用英文效果远好于中文，中文提示词遵循更差
3. **跑偏**：人像/产品易生成 UI 界面 + 乱码

**gen（Qwen Image 2.1）最稳**：提示词遵循好（中英文都行），不确定时优先 `gen`；编辑优先 `edit`。

## 二、提示词写法

### 通用结构
```
[主体描述] + [风格词] + [光影/氛围] + [质量词]
```
- 主体：清晰具体（"黑金香水瓶 + 月光倒影"）
- 风格词：`black and gold` / `luxury` / `cinematic` / `editorial`
- 光影：`golden rim light` / `moonlight` / `cinematic lighting`
- 质量词：`ultra high detail` / `8k` / `premium`

> **关键：用途 ≠ 内容**——提示词描述"画什么"，**不要写"做什么用"**。
> 要"背景素材"，描述背景内容（"黑金抽象流线 + 粒子，无主体"），**不要写"ppt 背景"**（否则生成 PPT 版式图）。
> 要"产品图"，描述产品（"黑金香水瓶 + 金色背景"），不要写"产品宣传图"。

> **提示词直接写完整**：工作流不接入提示词增强节点，提示词写得多具体，出图就跟得多具体。

### 人像提示词
- **特征描述 > 直接说名字**：说"东方古典美/黑金礼服/手持香水瓶"比"刘亦菲"更稳
- 换姿势：改动作描述（手托脸/全身站立/手持产品），或用 `edit` 对已有图下指令
- 加"无文字/无水印"：`no text, no watermark`
- 角色一致性：`edit --ref <角色参考图>` 传入角色参考图

### 商业品牌场景提示词模板
```
luxury [产品/人物], black and gold, [细节], black background, golden rim light,
high-end [产品/人物] photography, cinematic, premium, ultra high detail, 8k
```

### 编辑指令写法（edit 管线 · 提炼自 Qwen 官方 Edit Prompt Enhancer v2）

> 给 `edit` 写指令前过一遍这 9 条。官方增强器不接入工作流，这套规则由调用方（我们）手工执行。

1. **两个语言决策分开，不许混**
   - (A) 描述性文字（引号外的散文）：用户中文指令→中文写；英文→英文；其他语种（日/韩/泰/法…）→英文写。
   - (B) 渲染进图里的文字（双引号内的内容）：优先级 ①用户给了原文/指定语言→逐字照办 ②原图已有文字→跟随原图主导语言（哪怕指令是另一种语言）③原图无文字且未指定→跟随用户指令语言。引号内**必须单语**，不许中英混排、不许双语对照；"参数表/电影感/技术文档"风格靠版式实现，不许把标签换成英文。
2. **属性解耦，全强度**：只改用户点名的属性，把点名的改到" unmistakable"程度；其余一切保持输入保真。两种对称失败：**泄漏**（ sharpen 顺手改了色调、换背景顺手"清理"了没提的东西）与**欠编辑**（改了但看不出来）。
3. **保留物"点名不描相"**：未改动的内容只用类型/位置/角色指认（"保持背景、人物与构图不变"），**越具体描述越会被重绘漂移**——一条总括保留条款优于逐元素走一遍画面。只有真正要改的东西才描述外观。
4. **文字即字面量**：输出里会出现的可读文字必须逐字承诺、用双引号括出；**承诺不了逐字内容就不要添加文字**。不要逐条枚举原图屏幕/海报里的小字（等于命令模型重画它们，然后写崩——迹风上架图 v1/v2 屏幕菜单乱码的教训）。
5. **身份靠指认不靠形容**：人脸/产品/画风等最难保持的东西，来自参考图时直接指向 `<imageN>`，不要文字描述五官（描述会诱发重绘、损伤相似度）。
6. **多图标签强制**：N≥2 时必须用 `<image1>` `<image2>`…指代，禁止"图1/第一张/the first image"；并写明每张的角色——谁是 canvas（构图与未点名内容存活的底图）、谁供素材，各取什么。无 canvas 的生成（合影/海报）要自己选比例。
7. **写成指令不写成成品描述**：以操作开头（"把…改为…"），视角是"只拿着输入图的人"。
8. **尺寸与提示词分离**：`rewritten_prompt` 里**永远不写**分辨率/比例（"2:3""1920x1080""4K"一律不进）；比例走 `--size`。2K/4K/8K 是质量词不是比例词。描述性比例词→`--size` 映射：海报 2:3、竖版/手机 9:16、iPhone 全面屏 18:39、安卓全面屏 9:20、方形/头像/专辑封面 1:1、横版/壁纸/PPT 16:9、小红书/证件照 3:4、iPad 4:3、名片 9:5、A4 竖 5:7、电影 21:9、带鱼屏 7:3、全景 2:1。单图未指定尺寸→跟随原图；多图→跟随 canvas 图。
9. **肯定句、单段、无省略**：要求用肯定表述（"保持背景与输入图完全一致"优于"禁止改变背景"）；整条指令一段写完，不用省略号截断；含糊处自行做最合理决定并写死，不留两个备选。

## 三、比例与预处理（关键）

### 比例选择
| 用途 | 比例 | 尺寸 |
| --- | --- | --- |
| 竖版人像（代言人） | 3:4 | 1080×1920 |
| 方图（产品卡） | 1:1 | 1024×1024 |
| 全页大图（背景） | 16:9 | 1920×1080 |
| 竖卡（3:4 卡） | 3:4 | 1080×1920 |

### 设计前置：图位规划（关键）
> **生图前先定图位**：设计 deck 时，**先确定每页图的坐标 (x, y, w, h) + 比例，再按图位比例生成对应比例图**。避免"图生成完发现尺寸/比例不对，重新生成"的返工。

#### 图位 → 生成比例 对照
| 图位（deck DSL） | 比例 | 生成尺寸 |
| --- | --- | --- |
| 竖卡（3:4） | 3:4 | 1080×1920 |
| 方卡（1:1） | 1:1 | 1024×1024 |
| 全页大图（16:9） | 16:9 | 1920×1080 |
| 半页竖图 | 3:4 | 1080×1920 |

#### 流程
1. **设计阶段**：每页先定图位坐标 + 比例（DESIGN.md 的"图片张数与图位"）
2. **汇总素材清单**：全 deck 所有图位 → 每张图的用途/比例/位置
3. **批量生成**：按图位比例生成（独立 seed）
4. **预处理**：fit 函数按图位比例裁切缩放（绝不拉伸）
5. **质检**：inspect_image 看每张，不合格换 seed 重生成

### 预处理铁律：**按目标比例裁切 + 缩放，绝不拉伸**
```python
def fit(src, out, tw, th):
    im = Image.open(src).convert('RGB'); w, h = im.size
    tr = tw / th
    if w / h > tr:  # 太宽，裁左右
        nw = int(h * tr); x0 = (w - nw) // 2
        im = im.crop((x0, 0, x0 + nw, h))
    else:  # 太高，裁上下
        nh = int(w / tr); y0 = (h - nh) // 2
        im = im.crop((0, y0, w, y0 + nh))
    im = im.resize((tw, th), Image.LANCZOS)
    im.save(out, quality=92)
```
**踩坑**：直接 `resize` 到目标尺寸 = 拉伸变形（P10 刘亦菲拉伸变形的教训）。必须先裁到目标比例再缩放。

## 四、文字水印处理

- 部分图带水印（logo/乱码文字）
- **裁掉文字区**：如 `lmf_wide` 左侧有 "KK" logo + 乱码 → 裁右侧人物区
```python
# 裁右侧 65%（去掉左侧文字）
x0 = int(w * 0.35)
im = im.crop((x0, 0, w, h))
```
- 生成时加 `no text, no watermark` 提示词预防

## 五、批量素材策略（商业 deck）

- **独立素材 8+ 张**：产品（3-4）+ 代言人（2）+ 意境（1-2）+ 空间（1）
- **每张独立 seed**：避免雷同
- **避免单图用 3 次**：封面 + 收尾可首尾呼应同图，中间页必须独立
- **素材清单**（商业品牌 deck 示例）：
  ```
  产品：perfume/serum/ceramic/gift（方图 1:1）
  代言人：face（3:4 正脸）/ full（3:4 全身）/ wide（16:9 横版）
  意境：moon_art（莲花月亮）/ abstract（金流线粒子）
  空间：space（高端 SPA）
  背景：collection（产品组合全页）/ empire（商业帝国地图）
  ```

## 六、生成 → 预处理 → 用图 流程

```
1. 确定素材清单（deck 每页需要什么图）
2. 每张独立 seed 生成（gen，NSFW 走 krea2/klein）
3. 预处理：按目标比例裁切 + 缩放（fit 函数，不拉伸）
4. 看每张图质量（inspect_image），不合格的换 seed 重生成
5. 裁掉文字水印（如有）
6. 写进 deck DSL（IMG_EL 引用预处理后的图）
```

## 七、常见踩坑

| 踩坑 | 修正 |
| --- | --- |
| 直接 resize 拉伸变形 | 先按目标比例裁切再缩放（fit） |
| 图带文字水印 | 裁掉文字区 + 提示词加 no text |
| 单图用 3 次 | 每页独立素材，封面收尾可呼应 |
| klein 跑偏 | 换 `gen`（Qwen Image 2.1，最稳） |
| 人像不像特定人 | 特征描述 > 直接说名字；或 `edit --ref` 传角色参考图 |
| 同 seed 多张雷同 | 每张独立 seed |
| 图片比例不对 | 生成时选对比例（竖版 1080×1920/方图 1024/全页 1920×1080） |
| 提示词太简略 | 提示词直接写完整（无增强节点），主体+风格+光影+质量词 |

## 八、与 deck 的关系

- deck 生成前：**先定素材清单**（每页需要什么图），再批量生成
- deck DSL：`IMG_EL(IMG + '/xxx.png', x, y, w, h)` 引用预处理后的图
- 全页大图：图铺满 1280×720 + `opacity 0.4-0.6` 黑底 + 文字骑图
- 产品卡：方图 1:1 放进卡/或文字骑图
- 代言人：竖版 3:4 放进半页/或文字骑图
