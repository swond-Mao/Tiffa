# 配图版式库（layout-patterns.md）

> 专业 PPT 必须留**图片位**——纯文字页像"报告"，带图页才有"演示感"。
> 本文件定义 10 种带图版式，生成页面时按内容类型选用，让页面"有图可放"。
> 图片来源：① 用户提供 → 落到 `resources/images/`；② AI 生图 → `image-gen-router`；③ 暂缺 → **image 元素会自动渲染灰色占位块**，后放图重新编译即可。

## 图片元素 DSL

```js
{ type: 'image', x: 80, y: 150, w: 620, h: 420,
  path: 'resources/images/endoscopy.png',  // 文件不存在 → 自动占位
  objectFit: 'cover',                       // cover(裁切填满) | contain(完整)
  radius: 12,                               // 圆角
  caption: '内镜中心实景' }                  // 图说（占位时显示，也可作学术风图注）
```

## 10 种带图版式

| # | 版式 | 结构 | 图占比 | 适用内容 |
| --- | --- | --- | --- | --- |
| P1 | **左大图右文字** | 左图 55-60% + 右侧文字卡 | 图 ≥50% | 产品/设备/场景展示、案例 |
| P2 | **右大图左文字** | 左文字 + 右图 55-60% | 图 ≥50% | 同 P1 的镜像，版式交替用 |
| P3 | **上图下文** | 上大图 55-65% + 下方卡片/要点 | 图 ≥50% | 项目成果、现场照片 + 要点 |
| P4 | **全幅背景图 + 骑线文字** | 全屏图 + 蒙版 + 文字 | 图 100% | 封面、章节过渡（hero） |
| P5 | **图 + 洞察** | 主图 ≥50% + 右侧洞察框 | 图 ≥50% | 数据页配可视化图、实景 |
| P6 | **双图对比** | 左右两图 48%/48% + 中央 VS/箭头 | 各 ≥45% | 对比、before/after |
| P7 | **多图网格** | 2-4 张图网格（案例/团队/项目） | 每张 ≥200×150 | 团队、案例集、活动掠影 |
| P8 | **人物证言** | 头像图 120-160px + 引用文字 | 头像 | 专家评价、患者反馈 |
| P9 | **图 + 数据卡** | 左图 + 右侧 KPI 数据卡组 | 图 ≥45% | 实景 + 核心指标 |
| P10 | **时间轴 + 配图** | 横向时间轴 + 关键节点配小图 | 节点图 | 发展历程、项目里程碑 |

## 选型规则

- **hero 页**（封面/章节/结束）：P4 全幅背景图最震撼，其次 P1/P2 大图
- **内容页**：每页至少 1 个视觉载体（图/图表/大色块）——设计原则要求"每页至少 1 个视觉锚点"
- **学术风**：图用论文截图/实景摄影/流程图（证据化），禁营销插画
- **咨询风**：图用数据可视化或去饱和摄影（二选一，不混用）
- **占比纪律**：单页图片/图表 ≤3 个，总面积 ≤B 区 60%；L1 主视觉 B 区 ≥40%

## 与 dashiai 带图模板的关系

dashiai 的 `mediaSlots`（每个版式 1-6 张图槽位）思路已吸收：
- P1/P2 ← 左图右文/右图左文类
- P3 ← 上图下文类
- P4 ← 全幅影像类
- P6 ← 对比类
- P7 ← 陈列墙/多图网格类
- P8 ← 人物证言类

生成页面时：**先定版式（含图位），再定文字**——不要等文字填满再找地方塞图。
