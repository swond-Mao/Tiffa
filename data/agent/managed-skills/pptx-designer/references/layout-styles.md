# 版式语言库（layout-styles.md）

> 每页设计稿**必选一种版式语言**（L-*），相邻页不重复。
> **禁止默认回落**到"左大右小 / 并列等宽卡"——那是最平庸的选择。
> 坐标系 1280×720；画布 1280×720（build.js 自动映射）。

## Hero 冲击力版式（封面/章节/结尾/关键数据页）

| L-* | 版式 | 要点 | 实测示例 |
| --- | --- | --- | --- |
| L-diag | 斜切分割 | 对角线切分（阶梯斜线/大三角），标题骑在切线上，动势感；右/左半深色块 | 科技风 style_01 |
| L-fullbleed | 全页大图 | 图/色块占 100%，大标题骑图（≥72px 居中或左下），最冲击 | 科技风 style_02 |
| L-halfimg | 半页图+叠层 | 上 60% 大图 + 下卡压图边界，层叠纵深 | 科技风 style_06 |
| L-circle | 圆形聚焦 | 大圆内 KPI 巨数字（96px+），环绕胶囊标签 | 科技风 style_04 |
| L-ghost | 巨字背景 | 200px+ 半透明/深色巨字铺底，标题叠上 | 章节页巨字编号 |

## 内容节奏版式（正文页）

| L-* | 版式 | 要点 | 实测示例 |
| --- | --- | --- | --- |
| L-editorial | 杂志错位 | 块不同直线排列、错位网格、大留白、色块分区（拒绝等宽等高） | 科技风 style_03 |
| L-stack | 叠层卡 | 2-3 卡重叠（前卡压后卡露边），纵深层次 | 科技风 style_05 |
| L-asym | 非对称卡 | 1 大 hero 卡 + 2-3 小卡，打破对称网格 | consulting v4 P4 |
| L-rail | 时间轴/流程 | 横向节点 + 连接线 + 节点卡（节点上/下内容） | consulting v4 P15 |
| L-chart | 图表主视觉 | 图 ≥50% B 区 + 右侧洞察卡（KPI 数字 + 说明） | 科技风 P2-P5 |
| L-table | 表格 | 表头 Navy + 斑马行 + 金额徽章/状态徽章 | consulting v4 P18 |
| L-quote | 金句 | 大引号（160px）+ 44px 金句 + 署名 | consulting v4 P19 |
| L-bento | 便当格 | 混合尺寸格子（1 大 hero + 小格），无规则网格 | dashiai bento 类 |

## 选择规则（强制）

1. **每页设计稿标注 L-***（DESIGN.md 布局列），Step 5 生成严格按 L-* 实现
2. **相邻页 L 不重复**；连续 ≥2 页同 L 或同结构（同卡数/同宽卡横排）→ 返工
3. 封面/章节/结尾用 Hero 版式；正文按内容类型选节奏版式
4. 图表页用 L-chart：图 ≥50% B 区 + 右侧洞察卡（KPI 数字 + 一句洞察）
5. **视觉锚点**：每页 ≥1 个（≥48px 数字 / ≥40% B 区图或色块 / 大色块）——锚点是版式语言的核心
6. 打破网格的手段：斜切、骑线、错位、叠层、巨字、留白、色块分区——任选其一，禁止整页规整平铺

## 与 layout-catalog.md 的关系

- `layout-catalog.md`：1020 个模板按内容类型/布局族索引（选模板参考）
- `layout-styles.md`（本文件）：**版式语言定义**——模板选出来后，**吸收其布局意图 → 用 DSL 按 L-* 实现**（不填空）
- 流程：内容 → 选 L-* → 查 catalog 找相似模板看布局意图 → DSL 按 L-* 实现 → build.js
