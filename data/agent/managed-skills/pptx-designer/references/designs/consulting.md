# 商务咨询风（consulting）—— 权威、数据密集、结构化分析

## 适用场景
战略/行业研究、高管 review/董事会、投行/IPO 路演、咨询交付物、企业转型/组织变革、私募/风投/行研、尽职调查。

## 风格 DNA
- **Action Title 优先**：正文页主标题必须是**完整结论句**（"市场增长放缓，需聚焦存量客户"），不能只写"市场分析"关键词
- **Navy 权威感**：`#061F32` 主导全篇；颜色少、装饰少、信息强
- **结构图优先**：能用结构图讲清的内容，优先走信息结构图，不堆卡片
- **左对齐纪律**：标题、正文、图表说明默认左对齐；禁居中海报感
- **数据 + Source 可信**：数据页/正文页/结构图页必须有 Source/Footnote
- **无衬线商务感**：Arial + 中文黑体；禁衬线、书法、艺术字
- **极简不是空**：留白 25-40%，内容必须承担判断、论据、结论

## 色彩
| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| Navy 主色 | `#061F32` | 章节底、主框架、重点色块 |
| 皇家蓝 | `#001965` | 图表第二蓝 |
| Cyan | `#08A6F6` | 关键点缀；单页 ≤5% |
| 暗红 | `#5A0E13` | 涨色/警示（仅数据） |
| 绿 | `#177B57` | 跌色（仅数据涨跌） |
| 橙 | `#F47B39` | 中等风险，少量 |
| 中性灰 | `#E7E6E6`/`#808080`/`#44546A` | 表底、脚注、边框 |
| 背景 | `#FFFFFF` | 内页主底 |

配色比：Navy 系 20-35%，白底 ≥50%，中性灰 ≤15%，强调色合计 ≤8%。禁金色、中国正红、朱砂红、紫粉黄品红、彩虹色、阴影、发光、3D。

## 字体
Arial + 中文黑体。章节编号巨字 160-320px Bold；封面主标 60-96px；KPI 72-120px；**Action Title 32-40px Bold（B 区固定）**；副标/卡标 24-30px；正文 22-28px（**硬下限 ≥22px**）；数据标签 16-18px；Source/页码 14-16px。
单页字号 ≤5 种；相邻层级差 ≥6px。

## 页面类型要点
- **封面**：满 Navy 底或白底+左 1/3-1/2 Navy 色块；主标 60-96px 左对齐；主标+副标+公司/Logo+时间
- **目录**：纯白底；3-8 条，每条编号+章节名+摘要（总字数 ≥80）；3-4 项单行 N 列、5-6 项 2×3、7+ 项 2×4
- **章节扉页**：满铺 Navy，左 160-320px 低透明白色巨字编号，右章节标题 40-48px 白字+英文副标 20px 浅灰
- **执行摘要**：三栏 Context/Complication/Resolution，每栏 80-120 字；顶线/竖条紧贴栏标题（间距 ≤8px）
- **正文**：三栏卡（每卡 ≥60 字）/ 四六栏小卡 / 时间轴 4-6 步（1px Navy 主线）/ 大图配文（图 50-60%+3 Bullet）/ KPI 4 卡（大数字+单位+同比+说明）/ 对比 VS / 关键词矩阵
- **思维模型**：中央示意图（形状可用 SVG，**图内文字必须独立可编辑文本，禁烤进 SVG**）+ 右侧维度说明
- **数据图表**：白名单柱/折/瀑布/散点/树状/Mekko/2×2 矩阵；黑名单立体饼/立体柱/3D 散点/雷达；必备 Action Title+主图 ≥50%+洞察 80-150 字+Source
- **信息结构图（核心，占全篇 ≥20%）**：战略房屋 / 2×2 矩阵 BCG / Issue Tree 问题树（左→右扩展）/ 价值链 chevron / 流程图 / 桥图瀑布 / Mekko 块图 / 甘特路线图 / 多支柱网格 / 散点气泡 / 漏斗 / 组织地图——见腾讯方法论 12 子版式，结构图 = SVG 形状骨架 + 真实文本层

## 硬闸门（任一 → 返工）
1. Action Title 不是完整结论句，或 ≤8 字关键词
2. 正文/图表/结构图缺 Source/Footnote/页码
3. B/C 分割线缺失或非 1px 黑线；B 区起始 y 各页不统一（固定 72）；分割线未紧随标题（间距 >16px）
4. 字体非 Arial+中文黑体，或出现衬线/书法/文字烤进 SVG
5. 配色超出 Navy/皇家蓝/Cyan/警示色+中性灰范围
6. 金色、朱砂红、中国正红、紫粉黄品红、彩虹色出现
7. 单页字号 >5 种，或正文 <22px，或相邻层级差 <6px
8. 文字对比度 <4.5:1
9. L1 摄影类与数据可视化类混用
10. 结构图可用却堆卡片；全篇结构图占比明显不足
11. 结构图用曲线连接、心形/云朵/星形等非白名单形状
12. 图表出现 3D、雷达、螺旋或装饰背景
13. 任意页字数低于下限 70%
14. 占位文未清零
15. 装饰竖条/上边框悬空（与标题间距 >8px）
16. 卡片组末行残缺留坑（卡数与列数不匹配）；同组卡不等宽等高
17. 正文页内容未撑满 C 区（累计高 <85%），下半部大片留白
