# 红金政务风（redgold）—— 庄重、红金热烈、中文优先

## 适用场景
党政机关汇报、政务/公共部门、国企央企汇报、党课/学习宣讲、周年庆典/红色文化、表彰大会、纪检巡察。

## 风格 DNA
- **红金主视觉**：鲜明朱橙红 + 金色点缀 + 白底内页，热烈但不杂乱
- **美术层与内页分离**：封面、目录、章节过渡可更强视觉；正文/模型/数据页用稳定母版
- **中文优先**：正文、图说、图表标签、章节副标、致谢页均用中文；仅少量结构性英文（CONTENTS/PART/CHAPTER/PREFACE/SWOT/SMART/PEST/KPI）允许
- **密度优先**：空不等于高级；美术层和内容页都要有足够信息与视觉承载
- **配图贴题**：主视觉必须服务当前页面主题，禁止通用大景凑数
- **零旋转纪律**：卡片、文字、飘带、装饰、配图全部 0°（仅 SVG 图表内部几何线例外）
- **禁廉价符号**：禁印章语义、红绸铺满、整屏暗蒙版、局部矩形色块压图

## 母版
- A 留白区 y 0-48：完全留白，禁任何文字/标识/kicker
- B 标题块 y 48-110：中文主标 32-40px **宋体 CN Heavy**，黑字；禁中英并排
- C 内容区 y 110-660：正文/图表/配图/卡片
- D 页脚装饰条 y 660-700：红橙 3 段装饰条（`#C42819` 53% + `#EE5530` 26% + `#F26B40` 21%，禁等宽）+ 页码

## 字体
- 内页主标：宋体 CN Heavy / Source Han Serif CN Heavy
- 正文/卡片说明：OPPOSans M / PingFang / 微软雅黑（正文必须无衬线）
- 美术大字：华文楷体 900W / 宋体 Heavy（封面/目录/章节过渡）
- 封面 4 字主标 160/190/220 交错；章节 PART 数字 160-320；目录"目录"60；前言主标 40；B 区 32-40；卡标 24-30；正文 22-28；KPI 72-120；页码 14-16
- 内页字体 ≤2 套，美术层 ≤3 套；正文禁宋体大段、主标禁黑体、主标禁描边

## 页面类型要点
- **封面**：4 字成语双行错位，单字独立 box，字号 160/190/220 交错；金字 = 金渐变+投影+光晕；副标 0° 金色飘带；汇报人/时间红胶囊药丸
- **目录**：卡组列表型（章节 ≥4，PART 矩形/胶囊卡横排或 3×2）或故事叙事型（章节 ≤4，左图右内容+阿拉伯编号单列）；编号载体只能一种
- **章节过渡**：唯一推荐白底左右分屏——左 50% PART+巨数+红短竖条+中文章节名+副标+3 关键词；右 50% 主题摄影出血铺满；底部 D 区装饰条
- **前言**：大白卡包 ≥220 字长文
- **正文**：三栏并列卡（每卡 ≥100 字，红头白卡或标准白卡）/ 四六栏卡（标签+主体+说明三层）/ 时间阶段轴（线+圆节点）/ 大图配文（L1 ≥40%）/ 数据强调（KPI 72-120px，标签中文）
- **思维模型**：超大模型缩写（SWOT/SMART/PEST/KPI）+ 4-7 张说明卡，多页同款
- **数据图表**：主图+右侧洞察或 4KPI+主图；图例/坐标轴/单位必须中文；涨跌红绿

## 卡片规范
卡体三选一（单页最多混用 2 种）：
- A 标准白卡：圆角 12-16px + 1px 浅灰描边 + 白底无投影（通用首选）
- B 红头白卡：顶部红卡头 48-56px + 白底正文区（多栏分组/强调）
- C 红色实心卡：红底白字圆角 12-16px（核心洞察，单页 ≤1-2 张）

卡内 padding 上下 20/左右 24；卡间 gutter ≥24；卡组顶边误差 ≤4px；所有卡片严格 0°。推荐白卡:红卡 = 3:1 或 4:1。

## 硬闸门（任一 → 返工）
1. A 区出现任何文字/标识/kicker/SECTION/右上小字
2. D 区缺红橙三段装饰条，或 3 段完全等宽
3. B 区主标非中文、非宋体 Heavy、字号 <32px，或中英并排
4. 正文使用衬线宋体，或主标使用黑体
5. 页面出现非结构性英文（正文、图表、章节副标、致谢页）
6. 色板越界：米白底、冷暗红、纯橙、屎黄、蓝紫品红等禁色
7. 金色占比超限，或红白金比例失衡
8. 文字对比度 <4.5:1，或靠整屏暗蒙版保对比度
9. 任意可见元素非 0° 旋转（SVG 图表内部线条例外）
10. 出现印章语义元素、落款章、红底竖排白字章
11. L1 配图与页面主题不符，或通用大景在章节/内容页凑数
12. L1/L2 被局部矩形色块覆盖，或底图 opacity <0.85
13. 封面缺金渐变、投影、光晕任一项，或字下出现填色矩形
14. 目录编号载体不单一，或场景与版式不匹配
15. 章节过渡未走白底左右分屏 PART 现代版
16. 卡片 padding/对齐/填充率/零旋转任一失守
17. 思维模型多页不同款
18. 占位文未清零
