# 学术风（academic）—— 可信、证据驱动、蓝白克制

## 适用场景
高校答辩、科研结题、教学课件（理工医）、学术会议、学科评估、临床/医学汇报、课题开题、实验室组会、科研申报。

## 风格 DNA
- **学术可信**：蓝白浅灰基底，表达研究/证据/方法/结论，不做营销海报
- **撑满优先**：内容页 C 区累计高度 ≥96% 可用高，留白不是主要手段
- **证据化配图**：L1 必须是论文截图、真实实验/场景摄影、流程 SVG、显微/医学图之一
- **卡体克制**：常规卡浅底淡描边；深蓝实色卡只作语义凸显，限频使用

## 色彩
| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 主蓝 | `#1E4FA8` | 顶条、编号、强调 |
| 藏蓝 | `#0E3F8C` | 深底、章节、重点 |
| 浅蓝 | `#E8EFF8`/`#F0F5FC` | 卡片底、表头浅底 |
| 中蓝 | `#3D7BD9` | 链接、描边、图表第二色 |
| 警示红 | `#D9534F` | 关键词/异常；单页 ≤3% |
| 数据黄 | `#FFC107` | 图表第二序列；单页 ≤3% |
| 文本 | `#1A2230`/`#4A5568`/`#8B97A8` | 主/副/辅助 |
| 背景 | `#FFFFFF`/`#F7F9FC` | 主背景 |

配色比：蓝族 35-55%，白底 30-55%，浅蓝 0-35%，红+黄 ≤5%，金色 = 0。禁紫粉玫红、橙绿大色块、彩虹渐变、纯黑大底。

## 字体
- 封面英文长 title：48-64px Bold Serif；封面中文主标：60-96px Bold
- A 区主标 32-40px Bold 深蓝；卡内标题 24-30px Bold；正文 22-28px Regular；表格 18-22px
- KPI 巨数字 72-120px Bold；页码/注解 14-16px
- 字体家族 ≤2 套：思源黑为主；思源宋/Times 仅封面英文长标题或引文。禁楷体、行书、毛笔、艺术字、空心字、3D 字

## 页面类型要点
- **封面**：LOGO + 中文主标 + 英文长 title + 副标 + 汇报人 + 时间；可选深蓝顶条
- **目录**：3-6 条目，编号+中文标题+摘要；左深蓝栏或编号条
- **章节扉页**：大数字 + 标题 + 2-4 要点，全篇锁定一种样式
- **前言**：完整母版，C 区一段 ≥220 字长文，可首字下沉 + 底部蓝色强调句
- **正文**：双栏对照（两淡描边卡+中央连接+底部结论）/ 三栏并列 / 流程时间轴 4-6 步 / 大图配文（图 50-60%）/ 数据强调（KPI/圆环+注解+结论）/ 关键词矩阵 2×2 / 综合复杂（技术路线、实验设计 ≥5 类组件）
- **思维模型**：中央 SVG 结构图 + 维度说明，多页同字号同卡体同色阶
- **数据图表**：主图 ≥50% C 区 + 上方引导问题条；深蓝表头、浅斑马纹
- **感谢页**：延续封面/顶条体系；禁烟花、金装饰、印章

## 硬闸门（任一 → 返工）
1. 内容页未撑满（C 区 <476px 或留白过大）
2. C 区用深色实底或高饱和彩色实底
3. 红+黄 >5%、金色出现、用禁色
4. 字号低于下限（正文 <22px、卡标题 <24px）
5. 卡片缺标题/正文/数据段，或卡内连续空白带
6. 深蓝实色卡超限（单页 >1、全篇 >3、多卡页禁用）
7. 卡填充不符合低纯度规则，或渐变作卡背景
8. 正文页组件 <3 类、修辞 <4 种、层次 <3 层
9. 多卡页缺双重锚定（物理连接+共享锚点），呈散碎卡片堆
10. L1 视觉类型混杂，或配图 3D/卡通/营销插画
11. 文字溢出卡片、对比度 <4.5:1
12. LOGO/页码/顶条模式全篇不一致
13. 数据图表缺主图、洞察或关键数字
14. 占位文未清零
