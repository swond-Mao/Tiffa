# 视觉精修指南（visual-refinement）

> **何时读**：Step 7 编译后 / 用户说"不够高级/太规整/文字看不清"时。
> 本指南解决"内容正确但视觉不够高级"的最后一环——**视觉自校验闭环**。

## 一、核心能力：视觉自校验闭环（能看图时必做）

**当 `inspect_image`（视觉模型）可用时**，编译后必须走这个闭环，不要只看 lint 通过就交付：

```
build.js 编译 → qa_render.py 出 PNG → inspect_image 看图 → 诊断问题 → 修页面定义 → 重编译重验
```

- 渲染：`python <pptx-template-reverse>/scripts/qa_render.py <deck.pptx> -o qa.png --cols 3`
- 看图：`read <qa.png>`（视觉模型挂载时直接读图）
- **注意**：qa_render 是 .pptx→PNG，形状被简化（图片/光晕/渐变会比真实 .pptx 略糙），**真实 .pptx 效果更细腻**；看图判断布局/可读性，别因渲染简化否定效果
- 循环到视觉达标（或用户目检确认）

## 二、文字压图：必须加底衬（最高频翻车点）

**满版大图/全幅影像页，文字绝不能裸压照片**——浅背景上白字会消失。

做法：文字区先垫一个**半透明深色底衬块**：
```js
// 文字区底衬（opacity 0.55-0.68，圆角，垫在文字下）
{ type: 'roundRect', x, y, w, h, fill: '#0A0E1A', radius: 16, opacity: 0.62 },
{ type: 'text', x: x+30, y: y+20, ... }  // 文字压在底衬上
```
- 整页压图：先垫全页半透明暗层 `R(0,0,1280,720, fill:BG, opacity:0.45)`
- 局部文字：文字区垫局部底衬（opacity 0.6-0.68）
- **判断标准**：文字和背景对比度足够（深底白字 / 白底深字），压图文字区必垫底

## 三、图片处理三件套（避免生硬/变形）

1. **圆角**：图片套 `roundRect` 或 build.js 自动圆角（radius 12-16），别用直角生硬边缘
2. **渐变压暗**：图上叠渐变 `gradientBar`（从底/边向透明），压出层次 + 让压图文字可读
   ```js
   { type: 'gradientBar', x, y, w, h, from: '#0A0E1A', to: 'rgba(10,14,26,0)', radius: 12 }
   ```
3. **避免变形**：图片按**目标区域比例**预裁（PIL crop 到 16:9/4:3/3:4），不直接拉伸
   - 全幅 → 16:9；卡片方图 → 1:1；竖卡 → 3:4
   - 用 prep_imgs.py 类脚本批量裁切到目标比例再放入

## 四、光晕收边（glowOrb 别飘出画布）

- glowOrb 的 `x,y` 是**圆心**，`r` 是半径——确保 `x±r`、`y±r` 基本在画布内，别飘到贴边/溢出
- **alpha 控制**：科技风 0.14-0.22（宁淡勿浓），过浓像污染
- 光晕做**氛围**不做主角：1-2 个即可，别铺满

## 五、增强元素清单（build.js 支持，别只用基础 rect/text）

| 元素 | 用途 | 关键参数 |
| --- | --- | --- |
| `glowOrb` | 霓虹光晕/氛围 | x,y(圆心), r, color, alpha(0.14-0.22) |
| `gradientBar` | 渐变条/压暗遮罩/背景渐变 | from, to, radius |
| `opacity` | 半透明层次/玻璃卡 | 0-1，底衬 0.55-0.68 |
| `lineColor` | 描边（玻璃卡边框） | 配 opacity 用 |
| `decoBlock` / `kpiBlock` | 装饰块 / KPI 半透卡 | 见 component-guide |

**玻璃拟态卡**：`roundRect` + `opacity 0.7-0.9` + `lineColor` 描边 → 高级感的关键。

## 六、"高级感"自检清单（看图时对照）

- [ ] 文字对比度：压图文字有底衬？深底白字清晰？
- [ ] 图片：圆角？渐变压暗？无变形？
- [ ] 光晕：收边？alpha 适中？
- [ ] 层次：有半透明/玻璃卡/渐变，不是实色平铺？
- [ ] 留白：非对称？有呼吸感？
- [ ] 相邻页版式 L-* 错开？
- [ ] 渲染图 vs 真实 pptx：渲染简化是正常的，真实更细腻

## 七、常见"不够高级"诊断（看图后）

| 症状 | 病因 | 修复 |
| --- | --- | --- |
| 文字看不清 | 裸压图/低对比 | 加底衬/调对比色 |
| 图片生硬 | 直角/无遮罩 | 圆角 + 渐变压暗 |
| 图片变形 | 未裁目标比例 | 预裁到区域比例 |
| 光晕凌乱 | 飘出画布/过浓 | 收边 + 降 alpha |
| 平淡 | 实色平铺无层次 | 加玻璃卡/渐变/半透明 |
| 规整呆板 | 全对称等宽卡 | 非对称/错位/大小对比 |
