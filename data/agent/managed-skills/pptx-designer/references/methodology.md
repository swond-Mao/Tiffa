# PPT 制作方法论（methodology.md）

> 制作专业 PPT 的完整决策框架。核心：**内容决定版式，风格统一色调，每页一个明确设计依据**。
> 流程：需求澄清 → 大纲（STORY.md）→ 设计稿（DESIGN.md，每页五要素）→ 逐页生成 → 编译/预览 → 交付。

## 一、五步流程

| 步骤 | 产物 | 决策 |
| --- | --- | --- |
| 1 需求澄清 | 主题/受众/页数/调性 | 必问主题；其他默认（10-15 页、商务浅色） |
| 2 大纲 STORY.md | 叙事逻辑 + 页面骨架 | 意图对齐 → Hero/Supporting 分配 → 页面大纲 |
| 3 设计稿 DESIGN.md | **每页五要素契约** | 内容类型 → 布局 → 模板 → 强调用法（见 §三） |
| 4 逐页生成 | pages/slide_XX.js | 对照 DESIGN.md 五要素逐页实现 |
| 5 编译/预览/交付 | .pptx + 翻页 HTML | lint 校验（配色/溢出/母版/锚点） |

## 二、设计稿每页六要素（DESIGN.md 必填契约）

> **色调是全局的**——在最初选模板时确定（风格库/自定义模板），设计稿每页**不重复选色调**，只标注"强调色用在哪"（哪个数字高亮、哪个系列强调、哪个色块提亮）。

每一页必须声明以下五要素（色调全局已定）：

| # | 要素 | 说明 | 来源 |
| --- | --- | --- | --- |
| 1 | **内容类型** | 这页核心是什么？数据/KPI、对比、流程、图片、观点、列表… | STORY 大纲 |
| 2 | **布局模式** | 从布局库选（L-cover/L-metrics/L-compare…） | layout-library.md |
| 3 | **页面模板** | dashiai 式页面分类：封面/目录/章节/少文字/多文字/图表/图片墙/证言 | 见 §四 决策表 |
| 4 | **强调用法** | 全局色调下，本页强调色用在哪（可选：某数字/某系列/某色块） | 全局色调 + 内容 |
| 5 | **图位与锚点** | 0-4 张图位置比例；视觉锚点（巨型数字/大图/图表/大色块） | 布局模式自带 |

**决策顺序（不可倒置）**：内容 → 布局 → 模板 → 强调用法 → 图位/锚点。
禁止"先挑好看版式再硬塞内容"。

## 三、色调选型（全局，选模板时定）

1. **钩子模式强制询问**（Step 0）：制作前必问用户选哪个模板
2. 选项：dashiai 12 套风格色板 / 领域预设 3 套（academic/consulting/redgold）/ 自定义模板（profile_template.js 分析）
3. 选定后全篇一套色板 + ≤2 字体；风格只约束色板/字体/视觉语言，不约束布局
4. 每页只标"强调色用在哪"（≤10% 面积）

## 四、内容类型 → 布局模式 → 页面模板 → 强调用法 决策矩阵

> 色调全局已定，下表"强调用法"列给出该内容类型的强调色使用建议（高亮哪个、强调哪个系列）。

| 内容类型 | 布局模式 | 页面模板 | 强调用法建议 |
| --- | --- | --- | --- |
| 开场/封面 | L-cover | 封面（美术层） | 主色大面积 + 强调色点缀 |
| 导航/目录 | L-toc | 目录（编号列表） | 主色 40% + 强调色编号 |
| 章节切换 | L-section | 章节过渡（巨字+副标） | 主色 60% + 强调 15% |
| 核心数据/KPI | L-metrics / L-duel | 数据页（巨型数字） | 强调色 15-20%（荧光/高饱和） |
| 趋势/时间序列 | L-trend | 图表页 | 图表双色（主 + 对比） |
| 排行/分布 | L-ranking | 表格页 | 表头主色 + 高亮强调 |
| 对比/问题对策 | L-compare | 少文字对比（双栏） | 双栏各一强调色 |
| 流程/步骤 | L-process | 多文字流程（步骤卡） | 编号强调色循环 |
| 架构/关系 | L-network | 多文字架构（SVG 骨架） | 主色阶 + 少量强调 |
| 观点/结论 | L-conclusion / L-quote / L-statement | 少文字（金句/结论） | 主色 + 金句强调 |
| 图片/场景 | L-photo-left/right/top | 多图（大图 + 文） | 图承载色调，文字用中性 |
| 团队/案例集 | L-grid | 图片墙（2-4 图） | 统一图框 + 主色标签 |
| 人物反馈 | L-portrait | 证言（头像+引用） | 主色边框 + 中性底 |
| 项目拆解 | L-case | 分镜（图+步骤） | 图 + 编号强调 |

## 五、页面模板类型（dashiai 分类，控制"文字量 × 图量"）

| 模板类型 | 特征 | 文字量 | 图量 | 典型布局 |
| --- | --- | --- | --- | --- |
| 封面 | 大标题 + 副标 + 单位 | 少 | 0-1（全幅） | L-cover |
| 目录 | 编号条目 | 中 | 0 | L-toc |
| 章节过渡 | 巨字 + 副标 | 少 | 0-1 | L-section |
| 少文字 | 观点/金句/结论 | 少 | 0-1 | L-quote/L-statement |
| 多文字 | 步骤/架构/要点 | 多 | 0-1 | L-process/L-network |
| 图表页 | 数据可视化为主 | 少 | 1（图表） | L-trend/L-metrics |
| 表格页 | 结构化数据 | 中 | 0 | L-ranking |
| 图片页 | 图为主 | 少 | 1-4 | L-photo*/L-grid |

**文字量 × 图量 自检**：少文字页禁堆正文；多文字页禁大图撑版面；图表页必须有洞察；图片页必须有图说。

## 六、色调选型（全局，选模板时定）

1. **用户指定** → 直接用（"用 theme02 炫光紫绿风"）
2. **场景匹配** → 从 dashiai-styles.md 12 套按场景选（金融→theme10 金色指数、科技→theme02、数据报告→theme05/06、政务→redgold、学术→academic）
3. **模板模仿** → profile_template.js 分析上传模板色板
4. **默认** → 商务浅色（academic 蓝白）

**风格统一纪律**：全篇一套色板 + ≤2 字体；风格只约束色板/字体/视觉语言，不约束布局（布局永远由内容决定）。

## 七、硬约束（每页自检）

1. 五要素齐全，决策顺序正确（内容→布局→模板→强调用法→图位/锚点）
2. 每页 ≥1 视觉锚点（巨型数字 ≥48px / 图 ≥40% B 区 / 大色块）
3. 相邻页布局模式不重复；对称版式全篇 ≤2 页
4. 图片位先定（L-photo*/L-grid），文字围绕图组织
5. 配色 ∈ design.json palette；字号符合阶梯；文本不溢出
6. 内容页必有母版（标题块 + 页码）；hero 页有冲击力版式

## 八、DESIGN.md 每页五要素样例

```markdown
| # | 内容类型 | 布局模式 | 页面模板 | 强调用法 | 图位 | 视觉锚点 |
| 04 | 核心数据/KPI | L-metrics | 图表页 | 荧光绿高亮 3 个巨数字 | 0 | 3 个 72px 巨数字 |
| 05 | 趋势/时间序列 | L-trend | 图表页 | 2026 柱荧光绿强调 | 1 图表 | 柱状图 ≥50% |
| 12 | 团队/案例集 | L-grid | 图片墙 | 主色标签 | 4 图 | 4 图网格 |
```

设计稿完成后，逐页生成时**严格对照五要素实现**，完成即验收。
