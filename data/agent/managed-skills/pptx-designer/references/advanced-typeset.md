# 高级排版手法库（advanced-typeset.md）

> **核心原则：不是所有内容都要用卡片，也不是所有页都要高级排版——按受众定比例。**
> - **稳重汇报**（医院/政府/学术/老头子领导）：卡片为主 + 少量高级页（封面/金句/结尾 1-3 页）
> - **商业推广**（品牌推介/商业路演）：高级排版为主 + 卡片辅助
> - **战略运营**（战略/投资人）：混合（卡片承载数据 + 高级排版做视觉冲击）
> 卡片（圆角矩形装内容）是**最偷懒**的排版——但**高级排版也不是越多越好**，要匹配受众。
> 本文件沉淀实测验证的**无卡片高级排版手法**，与 `layout-styles.md` 的 L-* 互补。

## 一、什么时候用卡片，什么时候不用

| 场景 | 用卡片？ | 理由 |
| --- | --- | --- |
| 3-4 个并列要点，需各自强调 | 可用 | 独立强调块，卡片合理 |
| 文字骑图（文字直接压在图上） | **不用** | 文字与图层叠 = 高级感，加框就废了 |
| 时间线/流程节点 | **不用** | 竖线 + 大年份 + 细线分隔即可 |
| 卖点/参数列表 | **不用** | 编号 + 文字 + 横线分隔（杂志目录风） |
| 杂志跨页（文字 + 图） | **不用** | 出血大字 + 图 + 金线骑字 |
| 数据/对比 | 可用 | 独立数据块需卡片强调 |
| 全页大图 + 文字 | **不用** | 文字直接骑图，加框破坏图 |

**判断口诀**：内容需要"独立强调块"才用卡片；能靠文字/图/线/留白构成的，一律不用卡片。

## 二、无卡片高级排版手法（实测验证）

### T1 文字骑图（文字直接压在图上）
- 文字 `opacity` 正常（白字压图，图加 `opacity 0.3-0.5` 黑底保证可读）
- 文字与图**层叠**（z 序：图在下，文字在上）
- 适用：全页大图 + 标题、产品图 + 品名
- 示例：P5 月华——左全页月华意境图 + 右"月华"巨字 + 卖点编号（文字直接排，无框）

### T2 出血大字（文字骑到页边）
- 大字 `x=40-90`（贴左页边），`fontSize` 90-120px
- 文字**骑到画布边缘**（出血），不是居中留白
- 适用：封面/愿景/金句页
- 示例：P2——"让东方/美学成为/世界语言" 90-110px 贴左出血

### T3 细线分隔（替代卡片框）
- 横线 `R(x, y, w, 1-3px, fill=LINE/GOLD)` 分隔列表项
- 竖线 `R(x, y, 2px, h)` 分隔列
- 替代"每个要点一个卡片" → 用细线分隔 = 杂志目录风
- 示例：P5 卖点——"01 东方草本 / 02 极致工艺 / 03 限量编号" 用横线分隔，无卡片

### T4 编号 + 文字（杂志目录风）
- `01  标题` + 下方小字说明，无框
- 编号用金色/大字，说明用灰字
- 适用：卖点/流程/要点列表
- 示例：P9——"2026 立足上海 / 2027 亚洲扩张 / 2028 全球帝国" 大年份 + 竖线分隔

### T5 负空间留白
- 大量留白（文字只占 1/3 页，2/3 留白）
- 留白本身是高级感（呼吸感）
- 适用：金句/愿景/品牌页
- 示例：P2 左下——"以东方为魂" 小字 + 大量留白

### T6 金线骑字（文字下方金线）
- 文字下方 `gradientBar` 金线（GOLD→GOLD3）
- 金线 + 小字说明（无框）
- 适用：图下方标注、强调文字
- 示例：P2 图下——"臻香 · 月华" 下方金线

### T7 全页大图背景 + 文字
- 图铺满 1280×720 + `opacity 0.4-0.6` 黑底 + 文字直接排
- 适用：产品组合/意境/背景页
- 示例：P4——全页产品组合大图 + 底部 4 列文字骑图

### T8 竖排文字（东方美学）
- 文字竖排（`text` 用 `\n` 连接单字），东方美学页
- 适用：品牌美学/东方意境页
- 示例：东方美学页——"月 华 器 物" 竖排

### T9 渐进缩放（条形/列表逐渐变大或递减）
- **条形图**：每条形 `w` 递增/递减（如 `w = 200, 320, 440, 560`），形成"逐渐变大"的动势
- **字号渐进**：列表项字号递减（如 `48, 40, 32, 24`）或递增
- **位置错位**：每项 `y` 递增 + `x` 递增（阶梯式），形成对角动势
- 适用：排名/趋势/递进关系
- 示例：条形图 4 条 `w=[200,320,440,560]` 逐渐变大

### T10 文字倾斜/旋转（rotate，动态张力）
- 元素加 `rotate: 角度`（build.js 支持，python-pptx shape.rotation，0-360°，负角 = 顺时针）
- **标题倾斜**：`rotate: -8 ~ -15`（微倾，动感）
- **装饰元素旋转**：色块/圆环 `rotate: 30-45`（对角张力）
- **大字骑线倾斜**：标题 `rotate: -10` + 骑在斜线上
- 适用：封面/章节/视觉冲击页（稳重汇报少用，商业/浮夸多用）
- 示例：`{'type':'text', 'text':'标题', 'rotate':-12}` 微倾动感

> **rotate 注意**：python-pptx 用 0-360°（-15° → 345°），build.js 透传 `el.rotate`。倾斜要"微"（-8~-15°），过大显乱。

## 三、浮夸视觉元素（奢华/浮夸风格）

### 粒子（鎏金粒子）
```python
def PARTICLES(x0, y0, w, h, n=20, color=GOLD):
    """随机鎏金粒子（小圆点），浮夸感"""
    import random
    random.seed(42)
    els = []
    for _ in range(n):
        px = x0 + random.randint(0, w); py = y0 + random.randint(0, h)
        s = random.choice([3, 4, 5, 6, 8])
        els.append({'type': 'ellipse', 'x': px, 'y': py, 'w': s, 'h': s,
                    'fill': color, 'opacity': random.uniform(0.2, 0.7)})
    return els
```
- 每页 20-40 个鎏金粒子（浮夸风格）
- 奢华/浮夸 deck 必加，科技/极简不加

### 鎏金光晕（glowOrb）
- 4 角 + 中心柔和鎏金光晕（`alpha 0.1-0.25`）
- 奢华感 + 氛围

### 上下鎏金渐变条
- 顶部/底部 `gradientBar`（GOLD→GOLD3，3px）
- 奢华边框感

### 装饰圆环
- 角落 `ellipse`（`opacity 0.1-0.2`）
- 装饰感

## 五、卡片 vs 高级排版 选择决策

| 内容类型 | 首选 | 次选 |
| --- | --- | --- |
| 封面/愿景/金句 | 出血大字 + 留白（T2/T5） | 全页大图（T7） |
| 产品/单品 | 文字骑图（T1）+ 编号（T4） | 全页大图（T7） |
| 卖点/参数 | 编号 + 细线（T3/T4） | 卡片（需独立强调时） |
| 时间线/流程 | 大年份 + 竖线（T4） | L-rail |
| 品牌美学 | 全页意境图 + 竖排（T7/T8） | 留白（T5） |
| 数据/对比 | 卡片（独立强调） | L-chart |
| 杂志跨页 | 文字骑图 + 出血（T1/T2） | 非对称（T1） |

**默认高级排版，卡片是例外**——除非内容确实需要"独立强调块"。

## 六、常见错误（卡片依赖）

| 错误 | 修正 |
| --- | --- |
| 每个要点一个卡片框 | 编号 + 细线分隔（T3/T4） |
| 文字和图都加卡片 | 文字直接骑图（T1） |
| 大字居中留白 | 出血贴页边（T2） |
| 整页规整平铺卡片 | 错位/留白/骑图（T1/T5） |
| 用卡片分隔列表 | 用细线分隔（T3） |
| 浮夸 deck 没粒子 | 加鎏金粒子 + 光晕 + 渐变条 |

## 七、与 layout-styles.md 的关系

- `layout-styles.md`：13 种 L-* 版式（含卡片类）——**版式骨架**
- `advanced-typeset.md`（本文件）：10 种无卡片手法（T1-T10）+ 浮夸元素——**高级感细节**
- 流程：选 L-* 骨架 → 用 T1-T10 手法实现（少卡片多排版，含渐进缩放/文字倾斜）→ 加浮夸元素（奢华风格）
