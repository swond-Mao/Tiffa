# 叙事原则（STORY.md 构建方法）

按顺序完成三步，未完成上一步禁止进入下一步。

## ① 用户意图对齐

构建 STORY.md 前，必须先回答 5 个问题（写进 STORY.md 开头）：

- **目标受众**：给谁看？汇报/路演/教学/评审/发布/内训？
- **核心目标**：讲完后希望观众相信什么、记住什么、做什么？
- **PPT 长度**：总页数预估（决定 Hero 页配额：10 页 2-3 页、15 页 3-4 页）
- **视觉调性**：3-5 个词锁定（"学术严谨/权威数据/政务红色/发布会式"）
- **内容边界**：哪些必讲？哪些不讲？哪些禁碰？

## ② 构建页面布局骨架

- **页面总数与分章**：每章包含哪几页
- **Hero 页定位**：先标出哪几页是 Hero（封面、结束页默认 Hero；中段选 1-2 页内容高潮）；Hero 占比 20-30%，两个 Hero 之间至少隔 1 个 Supporting
- **rhythm 曲线**：每页标 peak/valley/transition；连续 ≥3 页 valley 必须插入 peak 或 transition
- **非对称版式预算**：≥40% 页面用非对称版式（左大图+右文/全幅图骑线/非对称双栏/巨型数字/上大图下卡片/左标题右内容）
- **对称版式预算**：全篇最多 2 页可用对称版式（全屏视觉/N卡片横排/图表+洞察/居中金句/上下分栏），先决定用在哪两页

## ③ 构建页面大纲

每页按字段展开：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| `title` | 页面标题 | 市场规模与增长 |
| `type` | cover/catalog/section/content/ending | content |
| `role` | hero（视觉高潮）/supporting（信息承载）/transition（章节过渡） | hero |
| `rhythm` | peak/valley/transition | peak |
| `layout` | 版式（见下方速查） | 巨型数字+洞察 |
| `visual` | 视觉元素（L1 文件名/图表类型/大数字最小字号） | L1: market_growth.png（占右 60%） |
| `visual_role` | anchor（图是主角）/atmosphere（背景烘托）/evidence（图证观点） | anchor |
| `density` | 字数约XXX/图片N张/留白约XX% | 字数约220/图1张/留白20% |
| `anti_pattern` | **明确禁止的版式**（具体，不许写"避免单调"） | 禁止等宽卡片横排；禁止核心数字塞角落 |
| `description` | 1-2 句本页展示内容 | 巨型数字呈现核心增长率，配趋势洞察 |

### 版式速查

**对称版式**（全篇最多 2 页）：全屏视觉+大标题 / N卡片横排（⚠️全篇最多2页，Hero 禁用）/ 图表+洞察 / 居中金句/巨型数字 / 上下分栏

**非对称版式**（优先，≥40%）：左大图+右侧文字（55-65%）/ 全幅图+骑线文字 / 非对称双栏（60:40）/ 巨型数字+洞察（≥48px 锚点）/ 上大图+下方卡片 / 左标题+右内容（30-35% 窄栏）

### 版式选择约束

- 相邻页面必须用不同版式；连续 ≥2 页对称 → 第 2 页改非对称
- `左大图+右侧文字` 与 `非对称双栏` 合计 ≤ 全篇 40%
- 内容类型 → 最佳版式匹配：核心数据→巨型数字+洞察；产品展示→左大图+右文；观点金句→居中金句；对比→非对称双栏；流程/架构→非对称；数据密集→左标题+右内容

### 视觉锚点配置

逐页定 `visual_role`：anchor（对应 Hero 页，图 ≥40% B 区或配 ≥48px 数字）/ atmosphere（背景烘托，章节过渡）/ evidence（图证观点，从属文字）

## STORY.md Checklist（写完自查）

- ❌ Hero 页 <2 个或 >35%
- ❌ 连续 ≥3 页 supporting+valley（无视觉起伏）
- ❌ N卡片横排 ≥3 次
- ❌ 非对称版式 <40%
- ❌ 相邻两页版式相同
- ❌ 左大图+右文 与 非对称双栏 合计 >40%
- ❌ 任意页缺 role/rhythm/visual_role/anti_pattern 字段
