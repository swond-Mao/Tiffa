
### 添加供应商/模型后内核反复崩溃（2026-08-25 修复）
- **根因**：内核(omp)对 models.yml 自定义 provider 的 schema 校验极严——定义了 models 却缺 apiKey 行、apiKey 空串、或 contextWindow/maxTokens/cost.* 写成字符串，任一命中即**禁用整个 providers 配置**；无可用模型时内核 rpc-ui 启动直接 exit(1)，Tiffa 自动重启 ×3 表现为"反复崩溃"。切项目/恢复旧对话每次 spawn 新实例故必现。写入端 `models:write` 原本只做 YAML 语法校验，毒配置直接落盘。
- **修复**：三层防呆——① 主进程新增 `sanitizeModelsConfig`（幂等修复：补 apiKey "none"、数字字符串转数字）+ `validateModelsConfig`（轻量 schema 校验，不过拒绝写入并报中文字段错误），`models:write` 与启动自愈 HEAL 共用；② 渲染层 `serializeModelsYaml` 补双引号转义(`yq`)与数字强转(`ynum`)；③ 内核 exit≠0 且 stderr 含 "No models available"/校验失败时，`tiffa:exited` 事件带 `fatalReason` 给前端弹明确提示。
- **关键文件**：`electron/modules/models-config.ts`（新）、`electron/main.ts`、`electron/renderer/src/components/SettingsPanel.tsx`、`electron/modules/tiffa-instance.ts`、`electron/renderer/src/services/eventRouter.ts`
- **教训**：内核 schema 校验失败是"整体禁用"而非跳过单条；验证要在真实内核上做（`omp models list` + 沙箱 PI_CODING_AGENT_DIR），单看 UI 保存成功不代表配置可用。回归台架保留在 `.temp-crash-repro/`。

### UI 预设/下拉提供内核不支持的 api 类型导致崩溃循环（2026-08-25 修复）
- **根因**：设置面板三处预设（Ollama/llama.cpp/Ollama Cloud）和 API 类型下拉写出 `ollama-chat`（另有 `openrouter` 选项），但内核 schema 只接受 9 种 api；任一 provider 的 api 非法 → 内核**整体禁用所有自定义供应商** → 无可用模型 → rpc-ui 启动 exit(1) → 自动重启 ×3。
- **修复**：① 预设改 `openai-completions` + OpenAI 兼容地址（.../v1）；② 下拉移除 ollama-chat/openrouter；③ `validateModelsConfig` 增加 api 枚举校验（SUPPORTED_PROVIDER_APIS），保存时拒写；④ HEAL 新增 `extractUnsupportedApiProviders`，启动时把不兼容 provider 摘出隔离到 `models.yml.quarantine.bak.yml`，好配置照常生效。教训：UI 提供的可选值必须与内核 schema 枚举对齐，新增选项前先对内核做真实校验。

### 移动硬盘上 Playwright 下载浏览器内核卡死（2026-08-25 修复）
- **根因**：playwright 安装器下载 100MB+ 内核时用 `__dirlock` 文件锁自检（stale threshold），移动硬盘大文件写入慢导致锁更新超时被误判"已损坏"，三次均死在 30-40%。
- **修复**：绕开安装器——从 `cdn.playwright.dev` 手动下载对应版本 zip，解压到 `ms-playwright/chromium_headless_shell-<修订号>/`，写空文件 `INSTALLATION_COMPLETE` 标记。注意缓存目录结构：`ms-playwright` 在 `<便携home>/AppData/Local/`（LOCALAPPDATA 已重定向）。
- **关键文件**：`skill-deps/node_modules/`（playwright + @playwright/mcp）、`data/agent/mcp.json`（playwright MCP 注册，env 需带 HOME/USERPROFILE/LOCALAPPDATA 重定向）
- **教训**：升级 playwright 版本后必须重下匹配修订号的内核（browsers.json 里查 revision）；锁类工具在 USB 盘上大 IO 场景不可靠。
