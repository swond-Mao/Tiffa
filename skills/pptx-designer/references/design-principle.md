# 设计总则（pptx-designer 通用法则）

> 本文件是所有 PPT 项目的**通用设计宪法**，生成页面定义前必读。未命中领域预设风格时即为最终边界。三套领域预设（academic/consulting/redgold）见 `designs/`，命中时其**结构层**与本文共同生效。

## 设计总则（生成时不要复述，只检查落实）

- **一致性优先**：母版骨架、配色、字体、配图风格全程统一，禁止"个别页特殊处理"。
- **密度优先**：极简的前提是单元素信息密度足够大；空 ≠ 极简。任何一页内容稀薄都是失败。
- **配图骨架化**：配图必须承担叙事功能（占有效面积、与正文耦合），禁止 200×70 的"装饰小贴片"塞在标题栏。
- **大胆对比**：每页至少一个"视觉锚点"（超大字号/超大图/超大色块），其余元素围绕锚点组织。禁止所有元素趋近中间大小。
- **视觉节奏**：10 页以上必须有 2-3 页 hero 页，其余为 supporting 页。每页视觉重量不同，禁止"流水线感"。

## 1. 画布与母版（逻辑坐标 1280×720，自动映射真实幻灯片）

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A 标题块** | 0–120px | 120px | 主标题 32–40px bold，全篇位置一致 |
| **B 内容区** | 120–660px | 540px | 一切正文、图表、配图、卡片 |
| **C 页脚条** | 660–720px | 60px | 左侧项目名（可选）+ 右侧页码 `NN / TOTAL`，14px 灰字 |

页面 padding：上下 20、左右 60–80px。封面/章节/结束页可自定义版式，内容页严格保持母版一致。

## 2. 颜色系统（≤4 hex + 面积分配）

`design.json` 的 `palette` 定义色板（lint 强制校验：页面元素颜色必须 ∈ palette ∪ 中性色黑白）。

| 色彩角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 主色 | ≤60% | 背景、大色块、标题栏底色 |
| 辅色 | ≤30% | 卡片背景、图表第二系列、分隔线 |
| 强调色 | ≤10% | 巨型数字、CTA、核心数据标注（Hero 页可 15-20%） |
| 中性色 | 剩余 | 文本、页脚、边框 |

- **Hero 页**：强调色可提升到 15-20%；**Supporting 页**：强调色 ≤5%。
- 禁止全篇每页色彩比例雷同（差异 <10% 视为雷同）。
- 渐变：`linear-gradient` 用于卡片头/标题栏；背景图叠加 `opacity 0.4` 蒙版保证白字可读。

## 3. 字体系统（DESIGN.md 必须列全层级）

| 层级 | 字号（逻辑px） | 字重 | 用途 |
| :--- | :--- | :--- | :--- |
| 封面主标题 | 60–96 | bold | 仅封面 |
| 章节大字 | 60–80 | bold | 章节过渡、结束页 |
| **巨型数据/锚点** | **72–120** | **bold** | **核心数据——每页至少 1 个视觉锚点** |
| 页面主标题 | 32–40 | bold | A 区固定 |
| 卡片小标题 | 24–30 | bold/600 | 卡片头 |
| 正文 | 22–28 | regular | 段落（硬下限 ≥22px） |
| 引文 | 20–26 | italic | 「」 |
| 页码/脚注 | 14–16 | regular | 页脚 |

- 标题与正文允许不同字体个性；巨型数字必须与正文不同字重。
- 禁止全篇只用"系统默认无衬线"，DESIGN.md 必须写具体字体名。
- 相邻层级字号差 ≥6px，刻意制造大字对比。

## 4. 信息密度门禁

| 页面类型 | 最少元素 | 正文字数下限 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- |
| 封面 | 主标题+副标+主视觉 | 20 | ≥35% |
| 目录 | N 条目+引导句 | 80（合计） | — |
| 内容页·单主题 | 标题+正文+主视觉 | **180** | ≥30% |
| 内容页·卡片组 | 标题+引导+N 卡 | 每卡 ≥100（3 卡 ≥300） | — |
| 数据/图表页 | 标题+主图+洞察 | 80 | ≥50% |
| 章节过渡 | 章节大字+小标 | 30 | ≥40% |
| 结束页 | 金句+落款 | 20 | — |

- 默认留白上限：常规页 ≤35%；封面/章节/结束页不受限。
- **容器填充率 ≥85%**：卡片内内容垂直占用 ≥ 容器高度 85%。高 ≥380px 的卡正文 ≥100 字。
- **底栏锚定**：卡片尾部元素（引文条/标签条/按钮）必须钉到容器底部，禁止悬浮中段。
- **兄弟卡对齐**：同一行多卡，内部标题块/正文块/尾部元素 y 轴等高对齐（误差 ≤16px）。
- **焦点留白**：视觉锚点周围留 ≥40px 呼吸空间；禁止"均匀稀薄"的空白分布。

## 5. 配图系统

| 等级 | 用途 | 最小尺寸/占比 | 接入 |
| :--- | :--- | :--- | :--- |
| **L1 主视觉** | 页面主要叙事 | B 区 ≥40%（常见 560×420） | 卡片背景/一栏铺底/引文叠层 |
| **L2 支撑图** | 强化段落 | ≥280×180 | 段落旁/卡片头 |
| **L3 角标** | 全篇统一徽标 | ≤64×64 | 页脚左侧，位置全篇一致 |

- 严禁：200×70 小图塞标题栏；不同页 L3 位置漂移；L1 风格混杂（摄影/插画/3D 混用）。
- 具象场景（城市/人物/会议/实验室等）用生图（image-gen-router），结构化元素（流程图/时间轴/矩阵/巨型数字/角标）用 SVG。
- 生图产物必须落到 `resources/images/` 再引用，逐张核对内容/比例/清晰度/风格后再用。

## 6. 页面映射表（DESIGN.md 必填）

STORY.md 与 pages/*.js 之间的**契约**，逐页生成时严格对照：

```
| # | 文件 | 类型 | 角色 | 版式 | L1 文件 | 字数估算 | 留白% | 色彩分配 | 关键约束 |
| 01 | slide_01_cover | cover | hero | 全屏视觉+骑线文字 | hero.png | 30 | 35% | 主60%+辅30% | 全幅底图+左大标题 |
| 02 | slide_02_catalog | catalog | supporting | 左标题+右图文 | — | 120 | 25% | 主40%+辅25% | 每项 ≥30 字 |
```

## 7. 动笔自检（每页 10 条硬约束，任一不过 → 返工）

1. 母版区齐全（A 标题块 / B 内容区 / C 页脚含页码）
2. 标题块右侧无装饰小图，全篇位置严格一致
3. 本页 L1 主视觉占 B 区 ≥ DESIGN.md 规定（默认 30%），不得用 L3 角标顶替
4. 仅用 DESIGN.md 列出的 ≤4 种 hex 与 ≤2 套字体
5. 与上一页版式不重复；本页留白 ≤35%
6. 本页 ≥1 个视觉锚点（≥44px 元素 或 ≥40% B 区图），无则补巨型数字/大图/大色块
7. 与上一页视觉重量显著不同（最大元素面积比 >1.5:1 或版式结构不同）；连续 ≥2 页等宽卡片横排 → 返工
8. 色彩分配符合页面映射表：强调色只出现在焦点元素
9. role 与 STORY.md 一致：hero 页有 ≥40% 主视觉或 ≥48px 锚点数字；supporting 页不用 hero 级投入
10. 所有文本不溢出容器（build 自动 shrink 兜底，但页面定义仍要估算好）
