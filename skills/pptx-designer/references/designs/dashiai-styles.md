# dashiai 12 套视觉风格（来自 dashiai-ppt 主题库）

> 从 dashiai-ppt 的 12 套主题运行时中提取的**风格 DNA**（色板/场景/视觉语言）。
> 用户指定"用 dashiai 的 XX 风格"或需求匹配下表场景时，按对应风格设计。
> 色板为提取的**主色**，实际使用时按 design-principle.md 的面积分配规则（主 ≤60%/辅 ≤30%/强调 ≤10%）。

## 各风格色板与视觉语言

### theme01 轻拟态风（浅色柔和）
- 色板：`#5B8DEF`（主蓝）`#46B083`（绿）`#7A5AE0`（紫）`#E8503A`（红橙）`#E0A23A`（金）`#23232A`（深字）
- 视觉：浅底 + 柔和投影卡片、圆角大、图标化、亲和力
- 字体：黑体系（微软雅黑/思源黑体），标题 36-44px

### theme02 炫光紫绿风（深色科技）
- 色板：`#07090B`（近黑底）`#2FE07F`（荧光绿）`#4EA2FF`（亮蓝）`#9B7DFF`（紫）`#FF6FAE`（粉）
- 视觉：深色底 + 荧光渐变光效、科技感、发布会级冲击
- 字体：黑体 + 等宽点缀，标题 40-56px 白字

### theme03 深浅代码风（代码编辑器感）
- 色板：`#161513`（黑）`#84827C`（灰）`#F3F2EE`（米白）`#5F8F0C`（绿）`#B04A2F`（红棕）`#6E85FF`（蓝）
- 视觉：代码块、终端感、等宽字体点缀、双色高亮语法色
- 字体：中文黑体 + 西文等宽（JetBrains Mono/Consolas）

### theme04 玻璃糖果风（明亮多彩）
- 色板：`#27E021`（绿）`#FFC700`（黄）`#15A7F0`（蓝）`#FF9FE2`（粉）`#06140F`（深字）
- 视觉：糖果色大色块、玻璃拟态、圆润、年轻活力
- 字体：圆体/阿里普惠体，标题 36-48px

### theme05 色谱图表风（数据可视化）
- 色板：`#D8402E`（红）`#E2742C`（橙）`#3C9A52`（绿）`#EFBE2E`（黄）`#4DA0C6`（蓝）`#2C44A0`（深蓝）`#7A3C90`（紫）
- 视觉：白底 + 多色谱图表、强调数据可视化、图表主导
- 字体：黑体 + 数字用等宽/半粗，图表标签 14-18px

### theme06 深色图谱风（深底数据）
- 色板：`#26261F`（深底）`#C8F135`（荧光黄绿）`#FF5A3C`（橙红）`#3CA0FF`（蓝）`#FFD23C`（黄）
- 视觉：深色底 + 高亮荧光数据、图谱网络感、高密度信息
- 字体：黑体白字，KPI 数字 72-120px 荧光色

### theme07 冷白调研风（极简冷白）
- 色板：`#0E110B`（近黑）`#23C76A`（绿）`#2F7BFF`（蓝）`#F2A93B`（橙）`#8FD400`（黄绿）
- 视觉：白底为主、克制的强调色、学术调研感、留白较多
- 字体：黑体/宋体标题，正文 22-28px

### theme08 黑金实验风（奢华实验）
- 色板：`#16150F`（黑）`#ECEF35`（荧光黄）`#E7E6EE`（白灰）`#DEDCEA`（浅紫灰）
- 视觉：黑白基底 + 荧光黄点缀、实验性排版、留白大胆
- 字体：黑体 + 大字号对比，标题 40-64px

### theme09 深蓝杂志风（编辑杂志）
- 色板：`#050B22`（深蓝底）`#46E3C6`（青绿）`#4A86FF`（蓝）`#FFB27A`（橙）`#9F7BFF`（紫）`#FFFFFF`
- 视觉：深蓝杂志排版、大图叙事、栏目感、编辑设计
- 字体：标题宋体/黑体混排，正文 22-28px

### theme10 金色指数风（金融权威）
- 色板：`#0D0E11`（黑）`#F2F3F6`（白灰）`#6F9BD8`（蓝灰）`#5479E8`（宝蓝）`#8FA8E6`（浅蓝）
- 视觉：白/浅底 + 深蓝金指数感、权威数据、克制高级
- 字体：黑体 + 衬线数字点缀，标题 32-44px

### theme11 高能增长风（热血增长）
- 色板：`#1B1108`（深棕底）`#E22A0C`（红）`#FF6E2E`（橙）`#FFC07A`（浅橙）`#54D17A`（绿）
- 视觉：深色底 + 红橙增长曲线、上升箭头、热血动感
- 字体：黑体粗体，KPI 数字 72-120px 红橙

### theme12 声波霓虹风（潮流音乐）
- 色板：`#241E20`（深棕）`#C8C0BD`（灰）`#9A8F8C`（中灰）`#F15A29`（橙）`#3BB6EC`（蓝）`#BAF04F`（荧光绿）
- 视觉：霓虹灯管感、声波图形、暗底亮色、潮流音乐
- 字体：黑体 + 圆体，标题 40-56px

## 使用规则
- 用户明确说"用 dashiai 的 XX 风/模板风格"→ 按对应主题设计
- 需求场景匹配表中某主题 → 可用该主题风格
- 风格仅约束**色板/字体/视觉语言**，版式仍遵守 design-principle.md 母版与密度门禁
- 生图配图时，prompt 复用该主题的视觉关键词（如"深色科技感荧光渐变"）
