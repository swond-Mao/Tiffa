# Image Style Enhancer

## Trigger

当用户表达「生成图片」「画图」「做图」「出图」「做个封面」「做个海报」等意图时，**必须先激活此 skill**。

---

## 流程

### 步骤 1：判断风格明确性

**核心规则**：看用户提示里是否包含风格关键词（见下表"关键词"列），或者直接说了风格名字（"真实感""电影感""海报""二次元"等）。

- **提示足够明确**（包含风格关键词/风格名）→ 直接跳到 **步骤 3（扩写）**，用匹配的风格模板
- **提示不明确**（只说"画一张图""做个封面"但没说风格）→ 走 **步骤 2（选单）**

判断参考：

| 用户说 | 判断 | 行为 |
|--------|------|------|
| "画一个医生在办公室看片子，要像手机拍的" | ✅ 明确（真实感） | 跳过选单，直接扩写 |
| "帮我做一张卡通风格的猫" | ✅ 明确（卡通=4插画手绘） | 跳过选单，直接扩写 |
| "生成一张图，主题是医院大厅" | ❌ 不明确 | 走到步骤 2 让选风格 |
| "做一张智慧医疗论坛的海报" | ✅ 明确（海报） | 跳过选单，直接扩写 |
| "帮我画个东西" | ❌ 不明确 | 走到步骤 2 让选风格 |

### 步骤 2：询问风格方向（仅提示不明确时）

展示以下风格菜单让用户选择（可多选叠加）：

| # | 风格 | 适合场景 | 关键词 |
|---|------|---------|--------|
| 1 | 📸 **真实感摄影** | 产品图、人像、建筑、风景 | 写实、光影、质感 |
| 2 | 🎬 **电影感** | 故事性画面、氛围图、概念图 | 镜头语言、调色、景深 |
| 3 | 🎨 **海报设计** | 活动海报、电影海报、宣传图 | 排版感、视觉冲击、文字 |
| 4 | 🖌️ **插画手绘** | 水彩、素描、油画、扁平插画 | 笔触、材质、手绘感 |
| 5 | 🌸 **日系二次元** | 动漫角色、场景原画 | 赛璐璐、平涂、动态 |
| 6 | 📦 **3D渲染** | 产品展示、C4D风格、Q版 | 材质、光照、体积感 |
| 7 | 🕹️ **像素艺术** | 复古游戏、像素封面 | 像素格子、8bit/16bit |
| 8 | 🌌 **赛博朋克/科幻** | 未来场景、机械、霓虹 | 霓虹、义体、高对比 |
| 9 | 🏮 **中国风** | 国风插画、水墨、新中式 | 水墨、留白、写意 |
| 10 | ✏️ **线稿/草图** | 设计稿、漫画线稿 | 线条、未上色、速写 |
| 11 | 🔮 **奇幻/魔幻** | 游戏概念图、魔法场景 | 史诗感、光影特效 |
| 12 | 🎯 **自定义** | 混合风格等 | 用户自述 |

> 可直接问：「你想要什么风格？1-12 选一个或多个。」

### 步骤 3：收集用户简短需求

了解用户想生成什么内容（主体、场景、氛围、用途）。如果风格已明确，此步骤与风格判断同时完成。

### 步骤 4：按风格扩写提示词

使用下面的风格模板将用户简短需求扩写为**完整中文提示词**，用于 `ernie` 或 `t2i` 子命令。

**扩写原则**：
- 保留用户原始描述中的所有关键信息
- 加入风格特有参数（镜头、光照、色彩、渲染质量、构图）
- **关键：每一张图都必须加入 2-3 个"不完美"关键词**（参考下方的"反AI完美"必加词库），否则画面会呈现 AI 特有的"完美但虚假"感
- 输出一段连贯的**中文自然语言描述**，不要分点列表
- 如果需要画面包含文字，用括号标出文字内容，如 `标题为「XXX」`
- 末尾不追加英文模型专属标签（如 `--ar 16:9`），比例通过 `--custom` / `--size` 参数传递

### 步骤 5：选择工作流

扩写完提示词后，**让用户选择用哪个工作流出图**（不要自己决定）：

```
请选择生成方式：
1. klein  - Flux2-Klein 单分支，真实感最好，可自由设宽高
2. t2i    - 双分支并行（Klein + Z-image），出图快
3. ernie  - 文字/标题渲染最强
4. zimage - Z-image turbo，艺术质量高，1 步出图
5. krea2  - Krea2 Muse 艺术/anime，双主角 LoRA（liuyifei / kopiu）
6. edit   - 编辑/改图
```

附带推荐（仅参考，最终由用户决定）：
- 真实感/摄影/随拍 → 推荐 `klein`
- 海报/带文字/封面 → 推荐 `ernie`
- 插画/二次元/概念图 → 推荐 `zimage`
- 艺术化人物/动漫感/特定主角 → 推荐 `krea2`
- 快速出图/不看文字 → 推荐 `t2i`
- 改图 → `edit`

**krea2 主角选择**：若用户选 `krea2`，还需确认主角 —— `liuyifei`（默认）或 `kopiu`（仅当用户明确点名 kopi-u 时）。调 `gen` 时带 `--protagonist kopiu`，否则省略（默认 liuyifei）。

**zimage 参数说明**：
```
comfy.py zimage "<扩写后的提示词>" --size 1920x1080 --steps 1 --seed N
```
- 默认 1920x1080 横向，竖图用 `--size 1080x1920`
- steps 建议 1-4（1 最快，4 质量最高）
- 内置 zit_fdpo + Fun-Lora-Distill 两个 LoRA
- 可选 `--lora-person` 加载人物 LoRA

调用 `comfy.py` 前设置 `$env:PYTHONIOENCODING="utf-8"`

## 风格模板库

> **核心原则：真实感来自不完美。**
>
> AI 默认生成"完美但虚假"的画面——每个像素都对上焦、色彩均匀、对称平衡。
> 真正的照片是不完美的：轻微跑焦、紫边/色散、运动模糊、暗角、颗粒噪点、
> 肤色不均、毛孔/斑点/疤痕、头发凌乱、眼神光只有一个、左右脸不对称、
> 衣服褶皱自然不规整、光影有硬过渡。**越是"完美无瑕"，越像 AI 生成的。**
>
> 扩写时必须有意识地在每个模板中加入 2-3 个"不完美"描述词，否则结果会假。

### 1. 📸 真实感摄影（增强版）

> **核心心法**：AI 默认生成"完美但虚假"的画面。真实感来自刻意保留瑕疵。
> 扩写时每个提示词必须加入 3-5 个"不完美"描述词，否则画面会呈现 AI 特有的"完美但虚假"感。

```
{用户主体}，自然实拍感，非摆拍/非AI感，{环境/背景描述}，
{光照条件}（如：柔和的窗边侧光/金色逆光带镜头光晕/影棚单灯硬光打出阴影），
{构图方式}（如：中景/特写/抓拍感），{镜头特性}（如：85mm f/1.8 大光圈，
焦内锐利焦外柔和奶油般散景，轻微紫边/色散），
非完美状态——焦点可能略微在眼睛前方而不是眼睛上，睫毛和眉毛有自然缺失，
皮肤纹理真实可见（毛孔/细纹/色斑/轻微泛红/油光），不是光滑无瑕的AI皮肤，
不对称的自然五官，一边脸比另一边亮，{动态/表情自然抓拍感}，
暗角自然，可能有轻微噪点或胶片颗粒，画面不刻意完美所以真实，
后期处理克制，保留RAW的原始色调和影调范围。
【强制加入不完美要素】：{轻微失焦/运动模糊/过曝区域/手指遮挡/构图歪斜/背景杂乱/
表情不自然/光线不均/噪点明显/镜头眩光/压缩痕迹/截图界面痕迹}，
【去塑料感三件套】：皮肤保留毛孔级纹理禁用平滑算法，自然肤色不均泛红区暗沉区，
保留环境杂光和反射中的不一致色温。
```

**变体**：
- 环境人像：抓拍感、眼神不看镜头、自然手势、户外混合光、背景有人/物虚化
- 产品/静物：微距景深极浅、对焦面清晰其余柔化、表面指纹/尘埃/使用痕迹、布光有主次
- 建筑/风景：超广角透视畸变、镜头渐晕、大气雾霾/灰尘、地平线不水平（自然拍摄感）、动态范围真实不过曝不欠曝
- **男友视角**：低角度、手持轻微抖动、近距离亲密感、私人空间氛围、手臂入镜、构图倾斜
- **窥视感**：模糊前景元素制造景深、虚化栏杆/植物前景、边缘遮挡、偷拍感

### 1a. 📱 随拍/手机快照（堪比实拍的"拍废片"技巧）

> 来源：Reddit 爆火提示词，被公众号 APPSO 等广泛转载。核心思路：**不要写"好看的照片"，要写"拍得很烂的随手快照"。**
> 越刻意追求平庸/失误，AI 越倾向于输出训练数据里数量最多的真实手机照片。

**手机抓拍通用模板：**

```
一张极其普通、毫无特色的{手机型号}照片，看不出明确的主题或构图——就像是随手一拍的快照。
画面中包含{描述画面元素：一段人行道、一辆车的一角、背景绿篱等零碎元素}，
照片有轻微的{运动模糊/手抖/对焦不准}，{阳光不均/灯光混杂}导致曝光{略过度/不足}。
角度{尴尬/随意}，几乎没有构图可言，整体效果平平无奇——
就像是不小心从口袋里掏手机时误按快门拍下的一张照片。
```

**人物自拍模板（增强版）：**

```

【自拍专属不完美要素】：{手指挡住部分镜头/手臂伸得太长/手机举得太高或太低/

衣服皱褶/皮肤油光/毛孔可见/轻微痘痘/黑眼圈/妆容不匀}，
```

## 扩写策略选择（何时用什么方法）

| 用户需求 | 推荐方法 | 说明 |
|---------|---------|------|
| 简单描述 + 明确风格 | 风格模板库 | 直接用对应风格模板扩写 |
| iPhone 自拍/日常随拍 | 1a 手机快照模板 | 强调不完美、生活感 |
| 高精度/复杂场景/zimage 分支 | 九步描述法（心法七） | 按照 9 步顺序构建，细节饱满 |
| 真实感摄影（通用） | 六步拟真法（心法六） | 确保包含 6 个维度的真实感要素 |
| 需要文字/海报 | 海报模板 + ernie | 文字渲染最强 |
| 艺术感/二次元 | zimage 分支 + 九步描述法 | zimage 适合高质量艺术图 |

**扩写流程建议**：
1. 先判断用户需求复杂度
2. 简单需求 → 风格模板库直接扩写
3. 复杂需求/zimage 分支 → 九步描述法构建框架
4. 真实感需求 → 六步拟真法 + 反 AI 完美词库
5. 最后检查：是否包含 3-5 个不完美要素？是否有去塑料感三件套？

## 真实感提示词写作心法（来自公众号/社区实战总结）

### 心法一：用"拍废片"思维替代"拍好片"思维

AI 训练数据中数量最多的是**普通人随手拍的平庸照片**，不是摄影师的作品。
当你描述"拍得很烂的随手拍"，AI 反而会输出最真实的照片。
**不要写**：高清、完美、精致、专业
**要写**：随手、随意、模糊、过曝、构图乱、抓拍、日常、普通

### 心法二：用具体镜头/机身型号替代抽象画质词

```
❌ 高清、超清、8K、极致画质
✅ iPhone 15 Pro 主摄拍摄、35mm f/1.8、等效28mm、手机自带相机、闪光灯直打
```

指定具体设备型号能激活模型对该设备成像风格的学习（CCD 的颗粒感、老 iPhone 的偏色、微单的虚化质感）。

### 心法三：用解剖学描述替代模糊赞美

```
❌ 好看、漂亮、自然、高级
✅ 右眉弓比左眉弓高0.3mm、左颧骨下方有5颗淡褐色雀斑、下唇厚度为上唇1.4倍
```

精确到可测量的视觉事实，AI 才能准确生成不完美的真实感。尤其在**皮肤质地**和**五官不对称**上。

### 心法四：场景/用途先行，告诉AI这是"什么场合的什么图"

先写用途再写内容：
```
一场学术会议的宣传海报 → 再用模板 3
一张周末朋友聚会的抓拍 → 再用模板 1a
医院科室的宣传栏展示 → 再用模板 3/9
```

### 心法五：去塑料感三件套

AI 图片最假的不是画错，而是"塑料感"。在提示词末尾加上：
1. `皮肤保留毛孔级纹理，禁用平滑算法`
2. `自然肤色不均，有泛红区和暗沉区`（破坏完美肤色）
3. `保留环境杂光和反射中的不一致色温`（破坏完美光线）

### 心法六：六步拟真法（强制要素）

每个真实感提示词必须包含以下 6 个维度的描述：

1. **【媒介与设备】**：(具体相机型号)、(镜头参数)、(胶片类型)
   - 示例：(富士 X-T4 拍摄)，(35 毫米 f/1.4 镜头)，(柯达 Portra 400 胶卷)
   - 手机示例：(苹果 15 Pro 前置镜头)，(iPhone 原生相机)，(无滤镜模式)

2. **【主体与状态】**：(抓拍 / 不经意姿态)、(自然微表情)、反精致细节：(凌乱)、(污渍)、(磨损)、(毛孔瑕疵)
   - 拒绝摆拍感，强调真实皮肤瑕疵、头发凌乱、衣服皱褶

3. **【环境与交互】**：(具体实景背景)、(路人 / 环境元素)、(空气微粒 / 尘埃)、(真实物理互动)
   - 背景要杂乱真实，有人物/物品入镜，有生活化道具

4. **【光影与氛围】**：(自然光 / 戏剧光 / 体积光)、(明确时段光线)
   - 示例：(黄昏逆光)、(室内硬光)、(柔和窗边光)、(霓虹反光)

5. **【光学瑕疵与质感】**：(胶片颗粒)、(运动模糊)、(色散)、(暗角)、(过曝区域)
   - 示例：(轻微胶片颗粒)、(动态模糊)、(色差)、(自然暗角)

6. **【特殊技巧】**：
   - 前景遮挡：(模糊前景元素) 制造窥视感和景深
   - 男友视角：(低角度)、(手持轻微抖动)、(近距离亲密感)、(私人空间氛围)
   - 技术缺陷美学：(欠曝区域)、(过曝高光)、(高感光度噪点)、(镜头眩光)、(手指遮挡镜头边缘)、(压缩痕迹)、(截图界面痕迹)

### 心法七：九步描述法（专业提示词构建框架）

> **适用场景**：需要高精度、细节丰富的提示词时（zimage 分支、高质量输出、复杂场景）
> 按照固定顺序构建提示词，确保逻辑通顺、细节饱满、无元素矛盾。

**九步顺序（严格遵循）**：

```
第一步：核心主体明确刻画
→ {主角名字/身份}，{年龄/性别/种族}，{核心特征}

第二步：主体外观 / 造型 / 服饰 / 神态细节
→ {发型/发色}，{五官特征}，{服饰材质/款式/颜色}，{表情/神态}

第三步：主体动作姿态与空间关系
→ {动作描述}，{姿态/站姿/坐姿}，{身体朝向}，{与环境的互动}

第四步：场景环境搭建（空间、场景元素、背景层次）
→ {空间类型}，{前景元素}，{中景元素}，{背景层次}，{环境氛围}

第五步：光影系统设计（光源类型、光质软硬、光影层次、氛围光效、明暗对比）
→ {主光源}，{辅光/反光}，{光质：硬光/柔光}，{阴影方向/强度}，{氛围光效}

第六步：色彩体系规划（主色调、辅色调、色温倾向、色彩对比、饱和度与明度）
→ {主色调}，{辅色调}，{色温：暖/冷/中性}，{色彩对比度}，{饱和度/明度}

第七步：材质与纹理表现（材质属性、表面质感、肌理层次、反光 / 通透 / 磨砂等特性）
→ {皮肤质感}，{服饰材质}，{环境材质}，{反光/透明/磨砂特性}，{纹理细节}

第八步：镜头与构图语言（拍摄视角、景别、焦距、景深、画幅比例、构图方式）
→ {拍摄视角：俯视/仰视/平视}，{景别：远景/全景/中景/近景/特写}，
{焦距/景深}，{画幅比例}，{构图方式：三分法/居中/对角线/框架式}

第九步：艺术风格与画风定义（写实 / 插画 / CG / 国风 / 二次元 / 胶片 / 电影感等）
→ {风格定义}，{渲染精度/画质强化}，{特殊效果}
```

**使用原则**：
- 按照 1→9 顺序构建，不要乱序
- 每步都要有具体描述，不要模糊笼统
- 避免无效修饰词（如"极致"、"完美"、"8K"等空洞词汇）
- 使用自然语言连贯描述，不要用权重符号或特殊语法
- 提示词为连贯的自然语言描述，内置 AI 可读重点符号

## "反AI完美"必加词库（增强版）

以下词用于**破坏AI默认的完美感**，使画面更像真实拍摄/绘制。每次扩写时至少选 3-5 个加入提示词末尾：

**光学不完美**：轻微失焦/柔焦/跑焦/色散/紫边/暗角/镜头光晕/畸变/彗差/渐晕/对焦不准/镜头眩光

**材质不完美**：颗粒感/胶片颗粒/噪点/纹理/纸纹/笔触/不均匀/粗糙感/使用痕迹/做旧/压缩痕迹

**拍摄不完美**：轻微抖动模糊/运动模糊/抓拍感/凌乱/不对称/不规则/自然光不均/杂光/反射/构图歪斜/角度尴尬/手抖

**人物不完美**：毛孔/细纹/色斑/雀斑/红晕/油光/汗珠/发丝凌乱/皮肤纹理/不对称五官/眼神不对焦/表情不标准/轻微痘痘/黑眼圈/妆容不匀

**色彩不完美**：色温不准/偏色/褪色/色彩偏移/肤色不均/高光溢出/阴影断层/色调分离/过曝/欠曝

**自拍专属不完美**（新增）：
- 手指挡住部分镜头/手臂伸得太长/手机举得太高或太低
- 角度歪斜/背景杂乱/表情不自然/眨眼瞬间/嘴角歪斜/眼睛闭着
- 头发凌乱/衣服皱褶/皮肤油光/毛孔可见/反光严重/手指阴影
- 截图界面痕迹/压缩痕迹/低分辨率感

**男友视角不完美**（新增）：
- 低角度仰拍/近距离拍摄/手持轻微抖动/私人空间氛围
- 手臂入镜/构图倾斜/仰拍显双下巴/角度尴尬/亲密感构图

**技术缺陷美学**（新增）：
- 欠曝区域/过曝高光/高感光度噪点/手指遮挡镜头边缘
