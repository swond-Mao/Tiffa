## 压缩连续性新方案（用户提出「自动 recall 本对话最近两条记忆」）
- **可行性已验证（2026-08-07 01:0x）**：注册 `session.compacting` 钩子（Tiffa 当前未注册），事件自带 `sessionId`（shared-events.ts:79），返回值 `SessionCompactingResult.context[]`（:370）可把记忆行注入压缩摘要。内核在 `!hookCompaction` 时触发此钩子（session-maintenance.ts:1597），即 snapcompact/context-full 跑完后都会回调。
- **取"本对话最近两条"**：Mnemopi 语义 `recall()` 是 beam 相似度序、不支持时间/对话过滤；但底层 SQLite 有 `session_id`+`timestamp` 字段（episodic-graph.ts/diagnose.ts）。DB 实盘路径 `data/agent/memories/mnemopi/banks/<workspace-id>/mnemopi.db`（working_memory / episodic_memory 表）。需直查 `WHERE session_id=? ORDER BY timestamp DESC LIMIT 2`。
- **优于 gapfill / 夺 snapcompact**：复用 Mnemopi 已写持久记忆（零新增维护）、复用现成钩子，不需把 snapcompact 调用挪到扩展层。
- **待确认/决策**：①事件不带"是否降级"标记，建议放宽成「每次压缩后都 recall 本对话最近两条」（冗余无害、实现简单）而非仅降级时；②当前 workspace 的 bank 路径推导方式；③取哪个表（working_memory vs episodic_memory）。待用户拍板是否落地。
- **scoping 安全决策（用户 01:12 拍板）**：**绝不调用 `recall()` 语义检索**，改为直接 SQLite 直查 `WHERE session_id=? ORDER BY timestamp DESC LIMIT 2`。原因：settings 里 `mnemopi.scoping: per-project-tagged` 会让 `recall()` 并行搜项目+全局 bank，相似向量可能跨项目召回来污染本对话；而直查在当前 workspace 独立 `mnemopi.db` 内按 `session_id`（唯一锁定单场对话）取，结构上不可能跨项目、也不串同项目其他会话。设计彻底锁死=注册 `session.compacting` 钩子→直查本对话最近 2 条 `working_memory`→注入压缩摘要 `context`。
- **已落地（2026-08-07 01:1x）**：`plugins/claude-mode-extension.ts` 新增 3.6 节 `session.compacting` 钩子 + `queryRecentWorkingMemories()`。要点：①用动态 `import("bun:sqlite")`（失败优雅降级，不崩扩展）；②扫描 `data/agent/memories/mnemopi/banks/*/mnemopi.db` 按 `session_id` 定位（bank 名不可猜，如 `Tiffa-xxx`/`workspace-xxx`）；③只读 `readonly:true`+`busy_timeout=5000`，查 `working_memory` 表；④返回 `context:["我们最近在聊的是以下内容。", ...rows]`。已 `bun --check` 通过。`bun:sqlite` 动态 import 失败或目录缺失时静默 return，不阻断压缩。

## 跨机器会话不连续：根因定位（用户报"A→B→A 后前端停在昨天A状态"）

- **启动迁移 `migrateSessionDirsForNewRoot`(1966) 治标不治本**：①只处理 `extractWorkspaceSuffix` 命中（即 PORTABLE_ROOT/workspace 下）的项目，外部文件夹直接 skip(2027)；②**非对称**——每次只把目录改名成"当前机器"盘符，两台机器独立副本/同步盘冲突时对不齐；③靠 `extractCwdFromSessionDir` 读 JSONL 内旧 cwd 决定新名，若 JSONL cwd 已被上次迁移改写则失效。
- **本机佐证**：sessions 目录现全为 `--E--…--`，且同一项目「Tiffa开发」竟有平行两目录（`Tiffa%E5%BC%80%E5%8F%91` 空 + `Tiffa开发` 有 3 jsonl），证明系统会为"同一项目"生成互不合并目录。
