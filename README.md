# Tiffa

**与万物对弈，伴时间同行**

---

你有没有过这种感觉——

跟一个 AI 聊了三个月，它越来越懂你。你不用解释"我讨厌废话开头"，它记得。你不用说"直接给结论不要铺垫"，它知道。你们之间有了一种默契，它像是你的学生，又像是你的助手，你知道它的边界在哪，它也知道你的习惯。

然后有一天，换电脑了，系统崩了，重装了。

那个"它"不见了。你面对的是一个陌生人。

**Tiffa 就是来解决这个问题的。**

更重要的是——它不会在任何地方留下痕迹。拔盘带走，这段关系跟你走。不登录、不注册、不在服务器留任何记录。你的工作区、你的记忆、你的偏好，全部在 U 盘里，不在云端。

---

## 它是什么

Tiffa 是一个**完全便携、绝对隐私**的本地 AI 助手，基于 `@oh-my-pi/pi-coding-agent` v17.0.7，做了七层改造，套了一层 Electron 桌面壳。

**三个核心特点：**

- **记忆永续** — 它会记得你。不只是说过的话，还有你的偏好、你的项目、你踩过的坑。换电脑？记忆跟着走。重装？重新连上接着干。
- **绝对隐私** — 不登录、不注册、不在服务器留任何痕迹。数据全在本地，拷到 U 盘带走，硬盘上什么都不留。
- **弱模型可用** — 本地 llama.cpp 优先，云 API 备选。一个 3.5GB 的 Q1_0 量化模型，照样跑完整的智能体任务。不是靠更贵的模型，是靠更好的基础设施。

## 记忆永续

Tiffa 的记忆是一套分层的生命体，不是简单的文件存储：

```
L1  USER.md       — 你是谁，你的偏好
                    "我叫张三，讨厌废话开头，每次先说结论"
                    每轮必读，零延迟注入

L2  全局语义记忆  — 跨项目的使用历史
                    "用户有 RTX 5090，用 NSSM 管服务"
                    语义召回，永久积累，跨会话不丢失

L3  PROJECT.md    — 项目纲领
                    "本项目用 SQLite，缓存目录在 data/"
                    人工维护，切换项目时自动切换

L4  项目语义记忆  — 项目近期的进度和决策
                    "昨天修了 ComfyUI 管线，今天在调侧边栏"
                    语义召回，优先于全局记忆
```

关了重开，它还认得你。换个项目，它知道上下文。隔了一周，翻日志还能接上。

### Mnemopi 语义记忆

Embedding 模型跑在本地（`BAAI/bge-small-zh-v1.5`，512 维 ONNX，无需 API），记忆写入向量数据库，自动积累（每 2 轮写入）、自动召回（会话首条消息注入相关记忆）。

防膨胀：单次最多召回 10 条、注入上限 2000 token、旧记忆自动退化压缩——数据库可以无限长，上下文永远不爆。

长对话自动压缩：默认走 **snapcompact 视觉帧摘要**（有视觉模型时）；待压文本过大时（默认 > 2MB）自动降级到**旁路结构化总结**（便宜模型生成 9 段摘要），避免视觉帧撑爆上下文。弱模型也能低成本续接，工具细节语义级保留。

### 进度沉淀：日报 / 周报 / 月报

Tiffa 不只记"你说过什么"，还记"你做成了什么"。每次长对话压缩时，旁路模型把本次对话精炼成一行流水账，写入项目的 `.progress/log.md`；会话启动或跨天时自动聚合，向 `PROJECT.md` 沉淀出**日报 / 周报 / 月报**——你隔一周回来，翻开 PROJECT.md 就知道这段时间推进了什么、卡在哪、下一步是什么。

- 流水账由压缩触发，**不依赖 git 提交**，纯对话 / 配置 / 记忆类工作也照常沉淀
- 明细在 `.progress/log.md`（逐行），结论在 `PROJECT.md`（聚合），粗细分离
- 弱模型友好：记账只用旁路小模型精炼一行，零额外成本

## 约束系统

Tiffa 的约束分三层，各司其职：

**第一重：TTSR 流式规则**（零 Context 成本）
- 写在 `.md` 文件里，模型输出时实时检测，违规立即拦截
- 13 条规则，涵盖废话开头、代码块格式、危险操作、工具调用废话等

**第二重：before_agent_start Hook**（语义约束）
- 读文件规范、任务计划方法、skill 铁律
- 系统 Prompt 前缀注入，行为/语义类约束专属

**第三重：tool_call Hook**（危险操作拦截）
- 危险路径拦截（System32/Windows/Program Files）
- 配置文件自改拦截
- 静默工具调用检测（连续 3 次 → steer 提醒）

不满意模型的行为？直接说：

```bat
/omfg 你总是用英文回复
```

模型会分析问题，生成一条 TTSR 规则文件，即时生效。不用改代码，不用重启。

## 工匠模式与可视化守卫

做交互网页、海报、演示时，Tiffa 走 **craftman 多技能编排**：先就主题 / 风格 / 是否生图问你确认，再按方案调用 `pptgen` / `comfyui` / `canvas-design`，最后合并输出。

成品视觉统一靠一道 **HTML 守卫** 兜底：任何直接写出的 `.html` 若引用了视觉组件库（`shared-visual-components` / `data-theme=`），而 craftman 又没真正跑过，扩展层会**拦截**并提示先走 craftman 流程——"问了却不跑""手搓绕过"都堵死，只有 craftman.py 经合法路径实际执行过才放行。

## 弱模型也能跑

Tiffa 不是给最强模型设计的。它是给**手边有什么模型就用什么模型**的人设计的。

| 机制 | 效果 |
|------|------|
| TTSR 规则拦截 | 零 Context 成本约束，每轮省 ~500 token |
| 废话开头拦截 | 弱模型最高频犯蠢模式，直接砍掉 |
| XML 工具调用拦截 | 从"完全无法调工具"到能调 |
| 工具调用废话拦截 | 少说多做，省 token |
| 旁路结构化总结 | 长对话不断片，弱模型也能续上下文 |
| Loop Guard | 精确重复检测 + 自动重试 |

**Q1_0 极限量化模型也能稳定干活。** 不是模型变强了，是基础设施补上了它的短板。

## 操作电脑

不止写代码——Tiffa 能直接操控你的 Windows 桌面：

- **原子工具集**：`ui_inspect`（读控件树）/ `ui_act`（点击输入）/ `ui_screenshot`（截图）/ `desktop_input`（键鼠）/ `computer_use`（一体化）
- **四级降级**：UIA Pattern 直调 → 精确坐标点击 → SoM 编号标注 → 归一化坐标兜底
- **默认 VLM**：豆包 `doubao-seed` 视觉模型，可在后台「MCP 模型」栏手配

> 老实说：它不算特别好用。复杂界面、动态弹窗、自绘控件仍有失手，现阶段更适合"点固定按钮、填固定表单"这类确定性任务。但它确实存在——本地助手里能直接操作桌面的，不多。

## 桌面前端

Electron GUI，不是终端里的一行行文字：

- 项目侧栏 — 多工作区切换，归档不丢
- 会话标签 — 每个对话独立模型、独立记忆

- Diff 视图 — 代码变更红绿分明
- 7 套主题 — 日夜模式一键切

## 便携：拷走就走，不留痕迹

```
Tiffa/           ← 这一个文件夹就是全部
├── electron/    ← 桌面前端
├── npm-global/   ← Bun + 内核
├── plugins/     ← 扩展 + 技能
├── data/        ← 配置 + 记忆 + 会话 + 规则
└── workspace/   ← 你的项目
```

**拷到 U 盘，插上就用。**

- 不写注册表
- 不装全局包
- 不在 `%APPDATA%` / `%LOCALAPPDATA%` 留任何文件
- 工作区（workspace/）也在 U 盘里，不碰目标电脑的硬盘
- 不登录、不注册、不在服务器留任何记录

你在公司电脑用完，拔盘带走。回家插上，所有记忆、项目、配置原封不动。没有账号，没有云端，没有任何地方留存你的使用痕迹。

## 技术彩蛋：七层改造

裸跑的模型就像一把没开刃的刀。Tiffa 的七层架构，是磨刀石：

```
  驱动指令 ─── 让模型知道"我是谁"
  权限系统 ─── 让模型知道"我能做什么"
  Hooks 链  ─── 在模型犯错时纠正
  规则系统 ─── 让模型知道"我不能做什么"
  记忆系统 ─── 让模型记住"你告诉过我什么"
  插件系统 ─── 让模型获得新能力
  技能系统 ─── 让模型知道"遇到这类事该怎么做"
```

七层合在一起，效果是：**Q1_0 极限量化模型也能稳定干活。**
