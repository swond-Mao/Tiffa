- 每个 skill 根目录必须包含 `SKILL.md`，使用 YAML frontmatter 声明 name、description、triggers、name_cn 等元数据，作为 agent 识别和触发的唯一依据。
- 复杂 skill 将可执行逻辑放入 `scripts/` 目录，SKILL.md 仅描述工作流和命令用法，实现与说明分离。
- 需要外部系统依赖的 skill（如 PDF、DOCX、Excel）在 SKILL.md 中明确列出 Python 包、npm 包、系统工具及降级 fallback 路径，缺失时优先尝试安装而非自行发明替代方案。
- 涉及用户决策的 skill（如 image-gen-router、dashiai-ppt、deep-research）强制要求先用 question 工具让用户选择分支/风格/画幅，禁止默认跳过选择直接执行。
- 输出文件命名遵循中英双语约定（中文用下划线或中文文件名，英文用下划线分隔），输出目录统一放在 skill 根目录下或当前会话工作目录。
