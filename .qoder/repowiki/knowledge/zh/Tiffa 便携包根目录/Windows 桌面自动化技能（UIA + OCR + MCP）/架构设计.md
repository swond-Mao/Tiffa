模块采用三层单向依赖结构：
- 核心层 `uia_core.py`：封装 UIA 控件树枚举、Pattern 直调（Invoke/SetValue/Toggle）、精确坐标点击、SoM 编号标注截图、Windows 内置 OCR 引擎调用、区域裁剪与 DPI 感知初始化，所有坐标统一为物理像素。
- MCP 服务层 `computer_use_mcp.py`：实现 MCP JSON-RPC 协议（stdin/stdout），注册 8 个工具处理器（ui_inspect / ui_act / ui_screenshot / ui_ocr / ui_find_text / ui_click_text / desktop_input / computer_use），每个处理器调用 uia_core 并返回 text+image 混合内容块，同时可选触发 Visual Grounding 子模型分析截图。
- 独立 Agent 入口 `computer_use.py`：不依赖 MCP 的便携版，通过 OpenAI function calling 接口直接循环截屏→LLM→执行→验证，用于非 MCP 场景。
- 依赖方向单向：MCP 层 → uia_core；两个入口互不依赖。`SKILL.md` 作为对外能力契约描述五级降级链与工作流。
