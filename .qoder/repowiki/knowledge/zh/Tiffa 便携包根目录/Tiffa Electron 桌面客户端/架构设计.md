采用标准 Electron 三进程架构：
- `main.js` 为主进程入口，负责创建 BrowserWindow、注册所有 `ipcMain.handle` 处理器、启动并管理 Tiffa 子进程（通过 `child_process.spawn` 调用 `bun.exe` 执行 `@oh-my-pi/pi-coding-agent/dist/cli.js`），使用 JSONL（每行一个 JSON）作为 IPC 协议。
- `preload.js` 通过 `contextBridge.exposeInMainWorld('tiffaDesktop', ...)` 暴露受控 API，隔离渲染进程对 Node.js 的直接访问，同时集成 `marked` + `highlight.js` 做 Markdown 渲染。
- `renderer/` 为纯前端资源：`index.html` 定义左侧项目面板 + 顶部会话标签 + 聊天区 + 右侧文件侧边栏布局；`app.js` 维护全局 state（项目、会话、消息缓存、最小化滚动条 minimap 等），通过 `tiffaDesktop.*` 调用主进程能力；`themes.js` 实现多套 HSL 配色主题系统，动态注入 CSS 变量。
- 进程间通信严格单向：渲染 → preload → main → 文件系统/子进程，事件通过 `webContents.send('tiffa:event'|'tiffa:exited')` 推送到渲染层。
- 多实例管理：`TiffaInstance` 封装单个 Tiffa 子进程生命周期（启动、崩溃自动重启最多 3 次、LRU 淘汰至 MAX_INSTANCES=8），`TiffaInstanceManager` 按 `cwd#sessionId` 键复用实例，支持项目级与会话级双粒度。
