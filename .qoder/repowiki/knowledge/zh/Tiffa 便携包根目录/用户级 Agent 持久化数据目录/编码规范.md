- 每个技能包以 `SKILL.md` 为入口描述，配合 `scripts/`、`references/`、`templates/` 等子目录组织实现细节。
- 会话目录采用 ISO 时间戳 + UUID 命名（如 `2026-07-28T13-47-02-564Z_019fa8fa-...`），便于按时间排序与唯一标识。
- 二进制资源通过 SHA-256 哈希命名（如 `data/agent/blobs/` 下的文件），同时保留 `.webp` 衍生版本。
- RAG 记忆库按用户/工作空间隔离，每个实体拥有独立的 `mnemopi.db` 文件，支持多租户并发访问。
- 日志与对话历史统一使用 JSONL 行式 JSON 格式，便于流式追加与增量处理。
- 规则文件通过 YAML frontmatter 声明 description/condition/scope/interruptMode，用于工具调用时的自动校验与中断。
