# 启动与便携架构

## 启动链路

### 桌面模式（推荐）

```
tiffa-desktop.exe (C# winexe，无控制台)
    │
    └── start-desktop.bat
            │
            │  chcp 65001 (UTF-8)
            │  set PORTABLE_ROOT=%~dp0
            │  cd electron/
            │
            └── electron.exe . --portable-root="G:\Tiffa"
                    │
                    │  main.js: 解析 --portable-root
                    │  创建 BrowserWindow
                    │  setupIpc()
                    │
                    └── TiffaInstanceManager.activate(workspace)
                            │
                            │  spawn(BUN_EXE, [cli.js, --mode, rpc-ui, -e, extension.ts])
                            │
                            └── Tiffa 内核就绪 → 渲染进程可交互
```

### TUI/终端模式

```
start-tiffa.bat [--tui|--web|--rpc]
    │
    │  设置环境变量（PI_CODING_AGENT_DIR, HOME, USERPROFILE）
    │  检测 Bun + 内核是否存在
    │  models.yml 不存在 → 从 .example 复制
    │  提取 KIMI_API_KEY（若未设置）
    │
    └── cd workspace/
        bun.exe cli.js -e extension.ts [--mode rpc-ui]
```

### VBS 启动器

`tiffa-desktop.vbs` — 无编译依赖的替代方案，通过 WScript.Shell 调用 start-desktop.bat，隐藏控制台窗口。

## 环境变量体系

### 核心变量

| 变量 | 值 | 设置位置 | 用途 |
|------|---|---------|------|
| `PORTABLE_ROOT` | 便携包根目录 | bat / main.js | 所有路径的锚点 |
| `PI_CODING_AGENT_DIR` | `{ROOT}\data\agent` | bat / main.js | 内核配置目录 |
| `HOME` | `{ROOT}\home` | bat / main.js | 用户目录重定向 |
| `USERPROFILE` | `{ROOT}\home` | bat / main.js | Windows 用户目录重定向 |
| `BUN_INSTALL` | `{ROOT}` | main.js | Bun 运行时定位 |
| `KIMI_API_KEY` | API 密钥 | 用户级环境变量 / bat 提取 | Kimi 模型认证 |

### UTF-8 编码治理

main.js 的 `_utf8Env()` 为子进程注入：

```javascript
{
  LANG: 'C.UTF-8',           // POSIX shell
  LC_ALL: 'C.UTF-8',
  PYTHONIOENCODING: 'utf-8:replace',  // Python stdin/stdout
  PYTHONUTF8: '1',                    // Python 3.7+ 全局 UTF-8
  NO_COLOR: '1',                      // 子进程不需要 ANSI 颜色
}
```

根因：Windows 控制台默认 CP936（GBK），子进程输出中文会乱码。

### 删除的变量

```javascript
delete env.NODE_OPTIONS;        // 防止 Electron 的 NODE_OPTIONS 污染 Bun
delete env.ELECTRON_RUN_AS_NODE; // 防止子进程误入 Electron 模式
```

## 便携路径解析

### PORTABLE_ROOT 确定优先级（main.js）

```javascript
1. --portable-root CLI 参数      // start-desktop.bat 传入
2. PORTABLE_ROOT 环境变量        // 系统级设置
3. path.resolve(__dirname, '..') // electron/ 的上级目录
```

### 关键路径派生

```javascript
BUN_EXE       = PORTABLE_ROOT/npm-global/node_modules/bun/bin/bun.exe
TIFFA_CLI     = PORTABLE_ROOT/npm-global/node_modules/@oh-my-pi/pi-coding-agent/dist/cli.js
EXTENSION     = PORTABLE_ROOT/plugins/claude-mode-extension.ts
WORKSPACE     = PORTABLE_ROOT/workspace
AGENT_DIR     = PORTABLE_ROOT/data/agent
```

### 扩展路径派生（claude-mode-extension.ts）

```typescript
PLUGIN_DIR    = import.meta.dir                    // plugins/
AGENT_DIR     = $PI_CODING_AGENT_DIR || ~/.omp/agent
PORTABLE_ROOT = resolve(AGENT_DIR, "..", "..")     // data/agent → 上两级
DATA_DIR      = resolve(AGENT_DIR, "..")           // data/
MEMORY_DIR    = DATA_DIR/memory
INBOX_DIR     = MEMORY_DIR/inbox
```

## 目录结构（便携包）

```
Tiffa/                          ← PORTABLE_ROOT
├── electron/                   ← 桌面前端
│   ├── main.js                 ← 主进程
│   ├── preload.js              ← IPC 桥接
│   └── renderer/               ← 渲染进程
├── npm-global/node_modules/
│   ├── bun/bin/bun.exe         ← Bun 运行时
│   └── @oh-my-pi/pi-coding-agent/ ← 内核
├── plugins/                    ← 扩展
│   └── claude-mode-extension.ts
├── skills/                     ← 18 个技能
├── data/
│   ├── agent/                  ← 配置（config.yml, models.yml, rules/）
│   ├── memory/                 ← 记忆（MEMORY.md, inbox/）
│   └── log/                    ← 审计日志
├── home/                       ← 重定向的用户目录
├── workspace/                  ← 工作区（用户项目）
├── python/                     ← Python 解释器（skill 用）
├── node/                       ← Node.js 运行时
├── start-desktop.bat           ← Electron 启动器
├── start-tiffa.bat             ← TUI/WebUI 启动器
├── tiffa-desktop.exe           ← 桌面启动器（C# winexe）
└── tiffa-desktop.vbs           ← VBS 启动器（无编译依赖）
```

## 首次运行

`start-tiffa.bat` 自动处理：
1. 创建必要目录（data/agent, home, data/memory, data/memory/inbox, data/log）
2. `models.yml` 不存在 → 从 `models.yml.example` 复制
3. 提示用户编辑 models.yml 填入 API Key

## 进程管理

### Windows 进程树终止

```javascript
function _killTree(pid, sync = false) {
  // Windows: taskkill /PID {pid} /T /F（树形终止）
  // 其他平台: process.kill(pid, 'SIGKILL')
}
```

原因：Windows 上 `SIGTERM`/`SIGKILL` 对子进程树不可靠。

### 模型配置热更新

```
models:write → 写入 models.yml
models:restart → killAll() + 重新 activate()
```

### 会话持久化

- 会话数据：`data/agent/sessions/{projectDirName}/{sessionId}.jsonl`
- 归档：`data/agent/sessions-archive/`
- 项目注册：`data/agent/projects.json`
