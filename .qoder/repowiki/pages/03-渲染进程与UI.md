# 渲染进程与 UI

## 架构概述

渲染进程（`electron/renderer/app.js`，~5008 行）是纯前端逻辑，通过 `window.tiffaDesktop` API（preload 桥接）与主进程通信。

布局：**左侧项目面板 + 顶部会话标签 + 中央聊天区 + 右侧文件/Todo/预览栏**

## 输出后处理管线

模型输出在渲染前经过三级修正：

```javascript
applyOutputFixes(text)
  ├── fixBareUrls(text)         // 裸 URL → Markdown 链接；file:/// → tiffa-local://；Windows 路径自动链接化
  └── fixCodeBlockLanguages(text) // 无语言标注的代码块 → inferCodeLanguage() 推断
```

### inferCodeLanguage 推断规则

| 模式 | 推断语言 |
|------|---------|
| `function/const/let/import/export` | javascript（含 React → jsx） |
| `def/class/from/import` | python |
| `<!DOCTYPE/<html` | html |
| `.#@{` + `:` | css |
| `SELECT/INSERT/CREATE` | sql |
| `package/func/type` | go |
| `fn/let/mut/impl` | rust |

## 事件处理

渲染进程通过 `tiffaDesktop.onEvent(callback)` 接收所有内核事件：

| 事件类型 | 处理 |
|---------|------|
| `ready` | 标记 tiffaReady=true |
| `agent_start` | agentRunning=true，显示加载态 |
| `agent_end` | agentRunning=false，恢复输入框 |
| `text_delta` | 流式追加文本到当前消息气泡 |
| `tool_call` | 渲染 ToolCard（智能摘要 + 可折叠详情） |
| `tool_result` | 更新 ToolCard 状态（成功/失败） |
| `extension_ui` | 弹出扩展交互对话框 |

### Stall 检测

- 3 分钟无事件 → 显示"可能卡住"提示 + 自动 steer
- 首次响应超时 → 提示用户

## ToolCard 智能摘要

每个工具调用渲染为可折叠卡片：

```javascript
summarizeToolCall(toolName, input) → { icon, title, detail }
```

| 工具 | 摘要 |
|------|------|
| `read` | 📖 读取 `filename` |
| `write` | ✏️ 写入 `filename` |
| `edit` | 🔧 编辑 `filename` |
| `bash` | ⚡ 执行命令（截断显示） |
| `search` | 🔍 搜索 `query` |

### Diff 视图

`extractDiff(toolResult)` 从 edit/write 结果中提取 unified diff，`renderDiffView(diff)` 渲染红绿对比视图。

## 主题系统

### 架构

`themes.js`（676 行）包含：
1. **7 套预设数据**（每套含 light + dark 两组 ThemeColors）
2. **注入引擎**：将 ThemeColors 转换为 CSS 变量，动态写 `<style>` 到 `:root`

### 7 套预设

| ID | 名称 | 风格 |
|----|------|------|
| `eucalyptus` | Eucalyptus | 莫兰迪色系，默认主题 |
| `claude` | Claude | 暖调橙色品牌 |
| `breeze` | Breeze | 现代清新护眼 |
| `sakura` | Sakura | 粉色日系 |
| `ocean` | Ocean | 深蓝海洋 |
| `dracula` | Dracula | 经典暗色 |
| `obsidian` | Obsidian | 纯黑极简 |

### 颜色格式

- HSL 不带 `hsl()` 包装：`'210 20% 18%'`
- CSS 中使用：`hsl(var(--bg-200))`
- 旧 hex 变量名通过别名映射兼容

### 3 种模式

- `light` — 强制亮色
- `dark` — 强制暗色
- `system` — 跟随 `prefers-color-scheme`

### ThemeColors 结构

```
background: bg000 ~ bg400（5 级背景）
text:       text000 ~ text600（7 级文字）
accent:     brand, main000~200, secondary100
semantic:   success/warning/danger/info 各 2~3 级 + Bg
border:     border100 ~ border300
special:    alwaysBlack, alwaysWhite, oncolor100
```

## 右侧栏

| 面板 | 功能 |
|------|------|
| 文件树 | `fs:listDir` 懒加载，目录优先排序，点击预览 |
| Todo | 解析 agent 输出中的 todowrite 事件，勾选状态追踪 |
| 预览区 | 代码高亮（hljs）/ 图片 / HTML iframe / Markdown 渲染 |

## 模型管理 UI

- 37 个供应商预设（OpenAI/Anthropic/Kimi/MiniMax/小米等）
- 2 步发现向导：输入 baseUrl + apiKey → `fetch:providerModels` 拉取模型列表
- 快速切换浮层：一键切换当前会话模型

## 会话/项目管理 UI

- 项目侧栏：按最近活跃排序，支持归档/恢复/删除
- 会话标签：每个对话独立进程、独立模型
- 历史加载：64KB header scan + 两轮 tool 重建
- 导出 HTML：单文件完整对话导出
