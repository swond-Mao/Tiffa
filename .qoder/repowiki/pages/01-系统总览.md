# 系统总览

## 项目定位

Tiffa 是基于 `@oh-my-pi/pi-coding-agent` v17.0.7 的**便携 AI 编程助手**。核心目标：让极限量化（Q1_0，3.5GB）的弱模型也能稳定完成智能体任务——代码读写、文件编辑、工具调用。

不靠更贵的模型，靠更好的基础设施。

## 七层改造架构

```
┌─────────────────────────────────────────────────────────┐
│  L7  技能系统    skills/ 18 个 SKILL.md       遇到这类事该怎么做 │
│  L6  插件系统    plugins/ 扩展 + hooks         获得新能力       │
│  L5  记忆系统    四层记忆 + Mnemopi            记住你说过什么    │
│  L4  规则系统    data/agent/rules/ TTSR        不能做什么       │
│  L3  Hooks 链   扩展 6 个 hook                 犯错时纠正       │
│  L2  权限系统    内核内置审批                    能做什么         │
│  L1  驱动指令    system prompt + 约束注入        我是谁          │
└─────────────────────────────────────────────────────────┘
```

## 模块划分

| 模块 | 路径 | 职责 | 运行环境 |
|------|------|------|---------|
| Electron 桌面前端 | `electron/` | GUI 壳：窗口、IPC、多实例管理 | Node.js (Electron 33) |
| Claude 化扩展 | `plugins/claude-mode-extension.ts` | 安全拦截、约束注入、断片补救、审计 | Bun (TypeScript) |
| Skills 技能层 | `skills/` | 18 个专业技能（生图/PPT/文档/调研等） | 由内核按需加载 |
| 数据/配置层 | `data/` | 规则、记忆、会话、模型配置 | 文件系统 |
| 内核 | `npm-global/.../pi-coding-agent/` | Agent 引擎（工具调用、上下文管理、Mnemopi） | Bun |

## 通信架构

```
Electron 主进程 (main.js)
    │
    │  spawn (BUN_EXE + cli.js --mode rpc-ui -e extension.ts)
    │
    ▼
Tiffa 内核子进程 (rpc-ui 模式)
    │
    │  JSONL over stdin/stdout（每行一个 JSON 事件）
    │
    ▼
Electron 主进程 ←→ 渲染进程 (IPC / contextBridge)
```

- **不是** HTTP/WebSocket，是进程间管道通信
- 每个对话可独立一个子进程（对话级实例）
- 最多 8 个实例并行，LRU 淘汰

## 便携设计原则

1. **PORTABLE_ROOT**：所有路径相对于便携包根目录解析
2. **环境变量重定向**：`HOME`/`USERPROFILE` → `portable/home/`，`PI_CODING_AGENT_DIR` → `portable/data/agent/`
3. **零全局依赖**：不写注册表、不装全局 npm 包、不留系统痕迹
4. **U 盘即用**：整个 `Tiffa/` 文件夹拷走即可运行

## 技术栈

| 层 | 技术 |
|---|------|
| 桌面壳 | Electron 33 + marked + highlight.js |
| 扩展运行时 | Bun 1.3.14 (TypeScript 原生) |
| Agent 内核 | @oh-my-pi/pi-coding-agent v17.0.7 |
| 本地推理 | llama.cpp（Q1_0 量化模型） |
| 语义检索 | BAAI/bge-small-zh-v1.5（本地 embedding） |
| 主题 | HSL Token 系统，7 预设 × 3 模式 |
