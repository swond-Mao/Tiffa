## 简介
Tiffa 文件浏览器经过重大重构，从传统的树形导航系统升级为现代化的扁平导航界面。新版本采用抽屉式预览设计，提供更直观的文件浏览体验。主要改进包括：

- **扁平导航系统**：摒弃深层嵌套的树形结构，采用直观的列表/网格视图
- **抽屉式预览**：点击文件时从右侧滑出预览面板，不干扰主工作区
- **双视图模式**：支持列表模式和网格缩略图模式切换
- **增强的交互体验**：支持目录切换、返回上一级、图片缩略图等现代化功能

## 核心组件
- 渲染进程 app.js
  - 负责扁平化文件树渲染、抽屉预览管理、视图模式切换等。
  - 维护文件浏览状态（当前目录、视图模式、抽屉状态）。
  - 实现文件预览标签管理和 Diff 视图渲染。
- 预加载 preload.js
  - 暴露 tiffaDesktop.fs.* 方法给渲染进程，屏蔽 Node 直接访问，确保只走 IPC。
- 主进程 main.js
  - 实现 fs:listDir、fs:readFile、fs:writeFile、fs:readImage 等 IPC 处理器。
  - 执行路径解析与安全检查（仅允许在便携根或工作区内），并设置文件大小上限。

## 详细组件分析

### 渲染进程：扁平导航与抽屉预览（app.js）
- **扁平文件导航**
  - setupSidebar() 初始化侧栏，监听刷新按钮，调用 listDir 获取目录项，以扁平方式渲染。
  - 支持列表模式和网格模式切换，使用 renderFileEntries() 统一处理两种视图。
  - 实现目录切换功能，支持"返回上一级"导航。
- **抽屉式预览系统**
  - openFilePreview() 管理 fileDrawer 抽屉面板，点击文件时从右侧滑出预览。
  - 根据文件类型自动选择预览模式（代码高亮、HTML iframe、图片显示、Markdown 渲染）。
  - 支持关闭按钮和间隙点击关闭功能。
- **视图模式切换**
  - switchFileViewMode() 在列表和网格视图间切换，持久化用户偏好到 localStorage。
  - updateViewToggleUI() 同步视图按钮的激活状态。
- **图片缩略图缓存**
  - loadThumbnail() 实现异步图片缩略图加载，带内存缓存机制（最多100张）。

### 主进程：安全 I/O（main.js）
- fs:listDir
  - 解析路径，限定在便携根或工作区内；读取目录项，返回 name/path/isDirectory/isFile/size/ext 等字段。
- fs:readFile
  - 解析路径，检查文件大小上限（默认 5MB），以 UTF-8 读取文本内容；超出限制返回错误。
- fs:writeFile
  - 受限于安全策略（见下文"权限控制"），通常仅在特定场景下允许写操作。
- fs:readImage
  - 用于图片预览，限制路径与大小，返回 base64 或错误。

## 性能与优化
- **扁平化渲染**
  - 文件列表按需渲染，避免深层嵌套导致的 DOM 复杂度问题。
- **懒加载与缓存**
  - 图片缩略图异步加载，带内存缓存机制（Map 存储，最多100条）。
  - 渲染进程维护 sessionMessageCache，减少重复渲染与 DOM 重建。
- **渲染优化**
  - 使用 IntersectionObserver 实现代码块懒高亮，进入视口才执行 hljs。
  - requestAnimationFrame 与 MutationObserver 合并绘制，避免频繁重绘。
- **大小限制**
  - 读取文件时限制最大体积（如 5MB），防止内存占用过高。
- **视图模式持久化**
  - 用户选择的视图模式保存到 localStorage，下次启动自动恢复。

## 故障排查指南
- 无法列出目录
  - 检查路径是否在便携根或工作区内；确认目录存在且可读。
- 读取文件失败
  - 检查文件大小是否超过限制；确认编码为 UTF-8；查看错误消息。
- 图片预览空白
  - 确认文件为支持的图片格式；检查路径是否正确；查看 readImage 返回。
- 写入被拒绝
  - 确认是否允许写操作；检查路径与权限；查看 write 相关 IPC 的错误返回。
- 抽屉预览不显示
  - 检查 CSS 类名是否正确应用；确认 drawerGap 可见性设置。
- 视图模式切换无效
  - 检查 localStorage 读写权限；确认视图切换函数调用正常。

## 附录：API 参考与安全最佳实践

### IPC API 参考（fs:*）
- fs:listDir(dirPath)
  - 输入：dirPath（字符串，目录路径）
  - 输出：条目数组 [{name, path, isDirectory, isFile, size, ext}] 或 {error}
  - 行为：仅允许在便携根或工作区内；目录优先、字母序排序
- fs:readFile(filePath)
  - 输入：filePath（字符串，文件路径）
  - 输出：{content} 或 {error}
  - 行为：UTF-8 读取；大小限制（默认 5MB）
- fs:writeFile(filePath, content)
  - 输入：filePath（字符串）、content（字符串）
  - 输出：{success} 或 {error}
  - 行为：受安全策略限制，需校验路径与权限
- fs:readImage(filePath)
  - 输入：filePath（字符串，图片路径）
  - 输出：{data}（base64）或 {error}
  - 行为：限制路径与大小，仅支持常见图片格式

### 安全最佳实践
- 路径白名单
  - 仅允许在 PORTABLE_ROOT 或 workspace 内操作，禁止越权访问系统目录。
- 大小限制
  - 对 readFile/readImage 设置上限，避免内存溢出。
- 写入保护
  - 对配置文件与敏感目录实施拦截；必要时要求用户确认。
- 错误处理
  - 统一返回 {error}，并在 UI 中友好提示。
- 审计与日志
  - 记录危险操作与异常，便于问题定位与合规审计。
